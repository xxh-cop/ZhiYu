# 专注手作与呼吸：怎么进入状态

## 一句话结论
进入专注状态可以从“固定一个小动作、放慢速度、把注意力放在触感和节奏上”开始；呼吸只是辅助，不需要刻意追求某种“标准呼吸”。如果出现头晕、胸闷，应立刻停止并休息。

## 一个简单的开始流程
1. **收桌面**：只留当前需要的材料，手机静音或放远。
2. **定一个小目标**：例如“编三行”“缝十针”“剪一个外轮廓”。
3. **放慢**：把动作速度降到平时的七成，感受材料阻力。
4. **注意触感**：线的摩擦、纸的厚度、泥的湿度，用一个词描述。
5. **短暂停顿**：完成小目标后停 10 秒，看看肩颈和呼吸有没有变化。

## 呼吸引导怎么用
- 可以跟随应用内的呼吸引导，吸气和呼气都以“不憋气、不勉强”为准。
- 如果刻意延长呼吸让你不舒服，就回到自然呼吸，只保留手作节奏。
- 不需要在情绪很激动时强行做深呼吸，先安全停下更重要。

## 常见误区
- 把“专注”当成必须达到的状态：走神很正常，发现后回到手上即可。
- 用长时间不动来证明专注：定时起身活动，避免颈肩僵硬。
- 用呼吸练习替代求助：持续不适或情绪失控时，联系可信任的人或专业热线。
