# 布艺基础缝合步骤

## 一句话结论
布艺缝合的基础顺序是：裁布 → 对齐布纹 → 固定 → 缝合 → 修剪缝份 → 熨烫 → 翻面/收口。新手最容易忽略的是布纹方向和缝份宽度，导致成品歪斜或尺寸不准。

## 材料与工具
- 布料、线、手缝针/缝纫机、珠针/夹子、剪刀、尺子、划粉、熨斗。

## 操作步骤
1. **裁布**：按纸样加缝份，注意布纹方向；条纹/格子要对位。
2. **对齐**：正面相对，边缘对齐，用珠针或夹子固定，避免缝时错位。
3. **缝合**：按统一缝份走线，起止回针；弧线处放慢速度。
4. **修剪**：剪掉多余缝份，弧线处剪牙口，翻面后才平整。
5. **熨烫**：先熨平缝份，再熨正面；温度按布料调整。
6. **收口**：留返口翻面，用藏针缝或明线收口。

## 常见失败
- 缝份不均：成品尺寸偏差、边缘起皱。
- 忽略布纹：成品拉伸变形。
- 不剪牙口：弧线翻面后堆积。
- 熨烫温度过高：化纤布熔化、留下亮痕。
- 缝纫机针距过大：接缝不牢，成品一拉就开；正式缝前先在废布上试针距和张力。

## 安全与免责
- 针、剪刀、熨斗均有风险；熨斗使用后及时断电，蒸汽避免烫伤。
