# 竹编与草编有什么区别

## 一句话结论
竹编以竹篾为骨架，靠经纬交织成形，强度和耐用性通常更高；草编以稻草、麦秸、蒲草等为材料，质地轻软、色泽温润，但耐折性和防潮性较弱。两者在材料处理、工具和收边方式上差别明显。

## 对比表
| 维度 | 竹编 | 草编 |
|---|---|---|
| 主材 | 竹材劈成的竹篾/竹丝 | 稻草、麦秸、蒲草、玉米皮等 |
| 预处理 | 破竹、劈篾、刮青、浸泡软化 | 选料、晾晒、熏蒸/染色、喷水回软 |
| 结构 | 经纬交织，起底后立身 | 多股编辫、盘绕或平编 |
| 强度 | 较高，可做承器 | 较轻软，适合装饰和轻载 |
| 防潮 | 需防霉，使用后通风 | 更易吸潮霉变，需干燥保存 |
| 常见风险 | 竹刺扎手、篾条断裂 | 草料脆断、虫蛀、染色不均 |

## 适用与不适用
- 需要承重、耐用、可清洗的器物，优先考虑竹编。
- 需要轻便、柔和、装饰性强的作品，草编更合适。
- 两者都不适合长期潮湿环境；草编尤其要避免水洗后暴晒变形。

## 操作要点
1. 竹篾先试弯，过脆的篾条不要强行编，避免断口伤人。
2. 草料编前喷少量水回软，编后阴干，不要暴晒。
3. 收边决定成品寿命，起底和收口要先练。

## 安全与免责
- 破竹、削篾会产生锋利竹刺，需戴防割手套并使用护手工具。
- 本卡为材料与工艺对比；具体地域流派、历史与代表作品待补权威来源并由传承人审核。
