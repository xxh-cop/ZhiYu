# 蓝印花布与扎染有什么区别

## 一句话结论
蓝印花布用镂空版把防染浆刮到布上，再入染、去浆，图案重复性好、线条较规整；扎染用捆扎、折叠、夹压防染，纹理随机、晕染自然。两者都可以做出蓝白效果，但版型逻辑和操作门槛不同。

## 对比表
| 维度 | 蓝印花布 | 扎染 |
|---|---|---|
| 防染方式 | 镂空版 + 防染浆（常用石灰/黄豆粉类配方，按项目） | 线绳捆扎、折叠、夹板 |
| 图案来源 | 刻版，适合重复纹样 | 捆扎方式，随机纹理 |
| 一致性与批量 | 同一版可重复生产 | 每件纹理不同 |
| 线条 | 较规整，边缘受浆料影响 | 柔和、放射状、晕染明显 |
| 主要工具 | 刻版、刮浆刀、染缸 | 线绳、夹板、染盆 |
| 难点 | 刻版与刮浆均匀性 | 捆扎松紧与折叠层次 |

## 适用与不适用
- 想做系列化、图案统一的蓝白布，优先蓝印花布。
- 想做单件、随机肌理、低门槛体验，优先扎染。
- 两者都涉及染料和废水处理，不建议在无通风、无收集条件的空间操作。

## 操作要点
1. 蓝印花布先试刮浆，确认浆料能完全覆盖镂空处且不糊版。
2. 扎染先试小样，记录捆扎圈数、松紧和折叠方向。
3. 染后都要充分清洗；蓝印花布还要规范去浆，避免残留。

## 安全与免责
- 染料、石灰等材料有刺激性和环境风险，需手套、口罩、通风和废液收集。
- 本卡为教学对比；具体配方、历史与地域流派待补权威来源并由工艺老师审核。
