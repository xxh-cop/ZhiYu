# 什么时候需要寻求专业帮助

## 一句话结论
当情绪困扰持续时间较长、明显影响睡眠/食欲/学习生活，或出现伤害自己/他人的念头时，建议尽快联系学校心理中心、专业机构或心理援助热线，而不是只靠手作自我调节。

## 可以参考的信号
- 情绪低落、紧张或烦躁持续较长时间，自己调整效果有限。
- 睡眠、食欲、注意力明显变化，影响到上课、考试或日常交往。
- 对原本喜欢的事情失去兴趣，持续感到无望或自责。
- 出现自伤、自杀念头，或觉得自己撑不下去。
- 使用酒精/药物、暴食催吐等方式应对情绪。

出现以上情况不代表“有病”，也不等于需要下诊断；它只是提示“现在值得找专业的人聊聊”。

## 可以找谁
1. 学校心理教育中心/辅导员（可先预约，说明想谈情绪困扰）。
2. 全国心理援助热线：12356（以应用内危机页实时配置为准）。
3. 紧急危险时：拨打 110/120，或前往最近医院急诊；不要独处。
4. 可信任的家人、朋友、老师：先告诉对方“我现在需要有人陪我”。

## 求助前可以准备什么
- 最近最困扰你的一件事，用一两句话描述。
- 睡眠、食欲、情绪变化大概持续了多久。
- 有没有想伤害自己的念头，以及是否已有计划。
- 你希望得到什么帮助：倾听、陪伴、转介还是紧急处理。

## 安全与免责
- 本卡为求助指引草稿，不构成诊断或治疗建议；待咨询师与危机负责人审核。
- 如果你正处于紧急危险中，请优先联系 110/120 或身边可信任的人，不要等待线上回复。
