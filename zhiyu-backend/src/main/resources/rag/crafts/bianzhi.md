# 编织

## 历史渊源

编织是人类最古老的手工技艺之一，可追溯至新石器时代。江西地区的竹编、草编、藤编等编织工艺源远流长，其中以景德镇浮梁竹编、瑞昌竹编最具代表性。编织工艺最初用于制作农具、生活用品，后逐渐发展为兼具实用与审美的工艺品类。2008年，瑞昌竹编被列入国家级非物质文化遗产名录。现代编织手作在材料上更加多元，除传统竹草外，还引入棉绳、毛线、皮革等材料，成为深受都市人群喜爱的手工体验项目。

## 工艺特点

编织以竹篾、草秆、藤条、棉线等线状或带状材料为原料，通过交错穿插、编结等方式成型。基本技法包括平编、斜编、六角编、绞编等。竹编讲究"起底—编身—收口"三步：起底决定器型底部结构，编身是主体部分，收口决定边缘美观与耐用度。编织的纹理由经纬材料的穿插规律决定，常见有人字纹、 hexagonal 六角纹、回字纹等。编织作品既有实用的篮、筐、盘，也有装饰性的壁挂、摆件。编织的节奏感强，动作重复而有序，手感明确。

## 疗愈价值

编织的重复性穿插动作具有节奏冥想效果——"一上一下"的规律动作帮助创作者进入安静专注的状态，思绪在重复中自然沉淀。编织需要持续的手指精细操作，能有效将注意力锚定于双手。材料从零散到成型的过程让创作者直观感受"从无到有"的建构过程，增强掌控感与成就感。编织的错误可拆可改，低焦虑的创作环境让创作者敢于尝试。完成一件编织器物后，其功能性带来持续的日常使用反馈，延长了疗愈效果。

## 制作流程概要

编织的基本流程以竹编为例包括：破篾——将竹子劈成均匀的竹篾条；刮青——去除竹篾表面青皮，便于编织；起底——用经篾与纬篾交叉编出底部；编身——沿底边向上编织器身，按选定的纹法穿插；收口——将篾条末端折入编体或用收口篾固定边缘；装饰——可加装提手、编花等装饰。初学者通常从简单的平编杯垫或小竹篮入手，约2至3小时可完成。复杂的大型编织作品可能需要数天至数周。棉绳编织（macrame）因无需特殊工具，入门更快，约1小时可完成小型挂件。
