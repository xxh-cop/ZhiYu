# 手作做失败了很挫败怎么办

## 一句话结论
手作失败很常见，先把“作品失败”与“我不行”分开：拆线、重裁、补救都是工艺的一部分。可以先判断是可修复、可改造还是需要放弃，再决定下一步，不必用一次成品评价自己。

## 先做三个判断
1. **可修复吗**：线迹歪了能否拆、纸剪断了能否补、泥裂了能否回收？
2. **可改造吗**：尺寸不对能否改成小件？颜色不满意能否叠加？
3. **需要放弃吗**：如果继续投入只会更烦躁，允许自己停下。

## 可以尝试的步骤
- 把失败点写下来：材料、工具、步骤、当时状态，各写一句。
- 只改一个变量重做小样，不要一次改全部。
- 给自己设一个“练习件”目标：不追求送人，只验证方法。
- 如果情绪明显升级，先离开桌面，走动或找人说说话。

## 不适合用“再努力一点”解决的情况
- 失败后持续自责、睡不着、不想吃饭，或出现伤害自己的念头。
- 手作变成必须完美、否则无法停止的强迫感。
这些情况更适合找咨询师或可信任的老师聊，而不是继续加练。

- 不要用尖锐工具或高温材料来“惩罚”自己；情绪激动时先停止操作。
