# 竹篾该怎么选

## 一句话结论
选竹篾看“宽窄一致、厚度均匀、颜色正常、无裂纹、柔韧度合适”：起底用较宽较硬的篾，细部用窄篾；太干会脆断，太湿会缩水松垮。新手先买已劈好的篾条，不要一上来自己破竹。

## 选型表
| 维度 | 起底/承重 | 侧壁/细部 | 收口/装饰 |
|---|---|---|---|
| 宽度 | 较宽 | 中等 | 窄 |
| 厚度 | 较厚 | 中等 | 薄 |
| 柔韧度 | 中，需支撑 | 较高，易弯 | 高，易藏头 |
| 检查重点 | 无裂口、无虫眼 | 厚薄均匀 | 表面光滑、无竹刺 |

## 选择顺序
1. 看颜色：自然竹色、无霉斑；过白可能经过处理，需确认安全性。
2. 摸表面：有毛刺的先打磨，否则编时扎手、磨线。
3. 试弯：轻轻弯成弧，能回弹不断裂为宜；一弯就断说明太干。
4. 统一规格：同一作品尽量用同一批篾，避免宽窄厚薄差异导致松紧不均。

## 常见误区
- 越绿越新鲜：含水太高，编后收缩松动。
- 越硬越好：过硬易断，尤其起底转折处。
- 只看宽度不看厚度：厚度不均比宽度不均更容易导致鼓包。

## 安全与免责
- 竹篾边缘锋利，挑选和打磨时戴防割手套；破竹需专用刀具和护手。
- 本卡为选型建议，具体竹种和含水率待竹编老师审核。

## 来源与审核
- 竹材分类与处理为通用教学整理，具体标准待补教材/工坊资料。
- 审核状态：待竹编老师或非遗传承人审核；记录见 `docs/rag-corpus-register-20261123.md`。
