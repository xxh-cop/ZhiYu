# 焦虑时做重复手作为什么可能有帮助

## 一句话结论
重复、有节奏、可预期的手作动作，可能帮助注意力从反复担忧中暂时转移，并带来“我能完成一点东西”的掌控感。它是日常调节方式之一，不是治疗手段，也不能替代专业帮助。

## 可能起作用的原因
- **注意力占用**：数针、绕线、折叠需要持续注意，减少反复想同一件事的空间。
- **节奏与呼吸**：稳定动作容易让呼吸放慢，身体从紧绷转向相对平稳。
- **可预期性**：材料不会反驳你，步骤有明确反馈，能带来安全感。
- **掌控感**：完成一小块、一小段，能积累“我可以做到”的经验。
- **表达出口**：颜色、纹理、形状可以承载说不清的情绪。

## 可以怎么开始
1. 选一个 5–10 分钟能完成的小动作：绕线、叠布、剪一条纸、编三行。
2. 不追求成品，只观察手、材料、呼吸的变化。
3. 如果越做越烦躁，可以停下来，换成走动、喝水或找人说说话。
4. 记录“做之前/做之后”的感受，帮助自己判断是否适合。

## 不适用的情况
- 情绪强烈到无法坐下、出现自伤想法或身体不适时，先联系可信任的人或专业热线，不要独自硬撑。
- 手作不能用来替代就医、用药或心理咨询。
