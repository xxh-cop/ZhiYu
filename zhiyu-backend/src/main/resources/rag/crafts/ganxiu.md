# 赣绣

## 历史渊源

赣绣，又称江西刺绣，是流传于江西地区的传统刺绣工艺，有着上千年的历史。赣绣起源于民间服饰装饰需求，在唐宋时期逐渐成熟，明清时期达到鼎盛。江西各地均有刺绣传统，其中以南昌、吉安、抚州等地的绣品最具代表性。赣绣吸收了苏绣的细腻、湘绣的写实之长，又融入了赣地客家文化的质朴风格，形成了独具特色的地方绣种。2010年，赣绣被列入江西省非物质文化遗产名录。

## 工艺特点

赣绣以平绣为主，兼施打籽绣、盘金绣、套针等技法。针法细腻平整，色彩以红、绿、蓝为主色调，对比鲜明又不失和谐。赣绣讲究"以针代笔、以线晕色"，追求画绣合一的艺术效果。绣线多用蚕丝线，光泽柔和；底布以绸缎、棉布为主。传统纹样以花鸟鱼虫、人物故事为主题，寓意吉祥。赣绣的 distinctive 特点在于"厚绣薄染"——绣面厚实立体，辅以淡彩渲染，兼具浮雕感与绘画韵味。

## 疗愈价值

赣绣的刺绣过程需要高度专注与稳定的手眼协调，一针一线的重复性动作具有天然的冥想效果。学习者通过感受丝线穿过布面的触觉反馈，能有效将注意力从纷扰的思绪中拉回当下。赣绣的"慢工"特质让创作者进入一种接近心流的沉浸状态，有助于缓解紧张情绪、舒缓压力。完成一幅作品后获得的成就感，也能增强自我效能感与价值体验。

## 制作流程概要

赣绣的基本流程包括：选稿设计——将图案描绘或拓印到绣底上；选线配色——根据图案选择蚕丝线的颜色与粗细；上绷——将绣布绷紧于绣架之上；刺绣——按照图案运用各种针法绣制；整理——绣完成后清洗、熨烫、装裱。初学者通常从简单的花卉纹样入手，先练习基本的平绣针法，逐步过渡到复杂的套针与打籽绣。一幅小型赣绣作品约需3至5天完成，大型作品可达数月。
