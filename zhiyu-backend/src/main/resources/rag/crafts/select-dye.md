# 染料该怎么选

## 一句话结论
选染料先确认纤维类型，再看是否需要水洗、日晒、鲜艳度和操作条件：棉麻常用活性染料，羊毛/丝绸常用酸性染料，化纤需对应分散染料；植物染适合自然色但重现性较低。用错染料类型，颜色再好看也洗两次就掉。

## 选型表
| 纤维 | 常见染料类型 | 优点 | 注意 |
|---|---|---|---|
| 棉/麻 | 活性染料 | 色牢度较好、色谱广 | 需盐/碱固色，废液需处理 |
| 羊毛/丝绸 | 酸性染料 | 色彩柔和、手感好 | 需酸性条件，控制温度 |
| 涤纶等化纤 | 分散染料 | 上色稳定 | 需高温高压，普通家庭难操作 |
| 任意天然纤维 | 植物染 | 自然、低饱和 | 重现性差，常需媒染 |

## 选择顺序
1. 看洗标/纤维成分，先排除“染不上”的染料。
2. 看用途：常洗的选色牢度明确的染料；装饰件可选植物染。
3. 看操作条件：没有通风、加热、废液收集条件，不要做高温/媒染工艺。
4. 先染 10cm 小样，做水洗和日晒测试，再染大件。

## 常见误区
- 一种染料染所有布：纤维不匹配会大面积掉色。
- 染料越浓越深：过量会导致浮色、手感发硬。
- 忽略废液：染液不能直接倒下水道。

## 安全与免责
- 染料多为化学品，需手套、口罩、通风；孕妇/过敏体质避免接触。
- 本卡为选型建议，具体染料品类和安全数据以产品说明书为准；待工艺老师与安全负责人审核。
