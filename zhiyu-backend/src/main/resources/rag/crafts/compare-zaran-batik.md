# 扎染与蜡染有什么区别

## 一句话结论
扎染和蜡染都属于防染印花：扎染用线绳捆扎、折叠、夹压等方式阻止染液进入；蜡染用熔蜡在布上绘出图案，靠蜡层防染。前者常见自然晕染，后者常见蜡裂形成的冰纹。

## 对比表
| 维度 | 扎染 | 蜡染 |
|---|---|---|
| 防染介质 | 线、绳、橡皮筋、夹板等物理捆扎 | 熔蜡（常用蜂蜡/石蜡混合，按项目配方） |
| 主要工具 | 线绳、夹板、染盆 | 蜡刀、熔蜡器、染盆 |
| 纹样特点 | 放射状、条纹、云团状晕染，边界较柔 | 线条绘制感强，蜡裂处出现细密冰纹 |
| 可控性 | 捆扎松紧和折叠方式决定效果，随机性较高 | 绘蜡线条较可控，冰纹仍有随机性 |
| 常见风险 | 捆扎不紧导致染液渗入过多 | 蜡温过高/过低、蜡层不均导致防染失败 |
| 适合入门 | 是，材料简单、容错较高 | 需要练习蜡刀和蜡温控制 |

## 适用与不适用
- 想做随机、柔和、不可完全复制的纹理，优先扎染。
- 想做清晰线条、图案叙事、冰纹肌理，优先蜡染。
- 两者都不适合在没有通风、没有染液处理条件的宿舍或密闭空间进行；需要按学校实验室/工坊规范操作。

## 操作要点
1. 先在小块布上试扎/试蜡，记录捆扎方式、蜡温、染色时间。
2. 染前充分浸湿（按染料说明），染后按规范清洗、固色、晾干。
3. 蜡染脱蜡需要热处理和废水收集，不能直接倒入下水道。

## 安全与免责
- 染料、助剂、高温蜡液均有安全风险，需佩戴手套、护目镜并在通风处操作。
