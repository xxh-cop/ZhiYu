# 竹编起底步骤：从竹篾到第一圈

## 一句话结论
竹编起底的核心是：选篾 → 软化 → 定经纬 → 起底 → 压紧 → 立身。起底没压紧，后面编得再整齐也会松垮；竹篾过干过脆则容易断。

## 材料与工具
- 竹篾（宽窄一致、无裂纹）、清水、防割手套、剪刀/篾刀、夹具或重物、垫布。

## 操作步骤
1. **选篾**：挑出宽窄、厚度接近的篾条，剔除有裂口和竹刺的。
2. **软化**：按需要喷水/浸泡回软，但不要泡到发霉；用前擦去表面浮水。
3. **定经纬**：先排经篾，间距均匀；再用纬篾一上一下交织。
4. **起底**：从中心或一端开始，每编一根就向中心推紧，保持四方/圆形轮廓。
5. **压紧**：用夹具或重物定型，检查是否有松动交叉点。
6. **立身**：底部达到目标尺寸后，把经篾折起，转入侧壁编织。
7. **收口**：最后压边、藏头，剪掉多余篾头并打磨。

## 常见失败
- 起底太松：成品歪斜、承重差。
- 篾条干裂：编到一半断裂。
- 经纬间距不均：侧壁出现鼓包。
- 收口不牢：边缘翘起、竹刺外露。

## 安全与免责
- 竹篾边缘锋利，需戴防割手套；破竹、削篾时刀口朝外。
- 本卡为教学步骤整理，具体起底法因器物而异，待竹编老师审核。
