# 剪纸

## 历史渊源

剪纸是中国最古老的民间艺术之一，其历史可追溯至公元六世纪南北朝时期。造纸术发明后，剪纸艺术逐渐在民间普及。至唐宋时期，剪纸已广泛用于节庆装饰、刺绣花样、祭祀供品等场景。江西地区的剪纸融合了南方剪纸的精巧细腻与北方剪纸的古朴豪放，形成了鲜明的地方特色。2009年，中国剪纸被联合国教科文组织列入人类非物质文化遗产代表作名录，江西剪纸作为重要分支位列其中。

## 工艺特点

剪纸以剪刀或刻刀为工具，在纸上剪刻出各种图案。主要技法有阳刻（保留线条、剪去空白）、阴刻（剪去线条、保留空白）和阴阳混刻三种。江西剪纸讲究"千剪不断、万剪不连"，即图案各部分之间必须保持连接不断裂。纹样以花鸟鱼虫、十二生肖、民间故事为主，构图饱满对称，线条流畅连贯。纸张多选用红色宣纸，象征喜庆吉祥；也有彩色套染剪纸，层次丰富。剪纸的工具简单，仅凭一把剪刀即可创作，门槛低而艺术上限极高。

## 疗愈价值

剪纸的剪刻过程需要稳定的注意力和精细的手部控制，每一次下剪都是一次决策与行动的统一。这种"手脑联动"的过程能帮助创作者将思绪聚焦于当下，暂时远离内心的纷扰。剪纸的对称构图和重复纹样具有秩序美感，有序的创作过程本身就能带来安全感和掌控感。完成一幅剪纸作品后展开纸面的瞬间，充满惊喜的正反馈能迅速提升愉悦体验。剪纸入门容易，适合各年龄段人群快速获得成就感。

## 制作流程概要

剪纸的基本流程包括：选纸——根据作品需要选择宣纸或彩纸，折叠或层叠；起稿——在纸上描绘图案轮廓，或直接用剪刀"盲剪"；剪刻——沿图案线条用剪刀或刻刀剪去空白部分，注意保持图案连接不断；展开——小心展开剪好的纸面，检查完整性；装裱——将剪纸作品衬于对比色底纸上，装框保存。初学者从简单的窗花、喜字入手，掌握折叠剪法后再练习复杂的自由构图剪刻。一幅小型剪纸作品约半小时至两小时可完成。
