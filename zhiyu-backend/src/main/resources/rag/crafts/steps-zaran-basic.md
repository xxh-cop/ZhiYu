# 扎染基础步骤：从捆扎到染色

## 一句话结论
扎染的基础顺序是：选布与设计 → 浸湿 → 捆扎/折叠/夹压 → 入染 → 氧化/固色 → 清洗 → 拆线 → 晾干。决定效果的关键不是染料多，而是捆扎的松紧、折叠层次和染色时间。

## 材料与工具
- 棉/麻等天然纤维布（先确认是否可染）、线绳/橡皮筋、夹板、染盆、手套、围裙、温度计。
- 染料与助剂按课程配方准备；废液收集容器。

## 操作步骤
1. **设计**：先画捆扎位置，标出希望留白和上色的区域。
2. **浸湿**：按染料说明把布充分浸湿，挤掉多余水分，保持均匀含水。
3. **捆扎**：线绳绕紧但不要勒断布；折叠越整齐，纹理越有规律。
4. **入染**：按说明控制温度和时间，适时翻动，避免局部染不透。
5. **固色/氧化**：按染料类型处理，不要跳过。
6. **清洗**：先冷水冲去浮色，再按规范清洗，直到水色变清。
7. **拆线**：完全清洗后再拆，避免染液回渗。
8. **晾干**：阴凉通风处晾干，避免暴晒褪色。

## 常见失败
- 捆扎太松：留白边缘糊掉。
- 布含水不均：出现深浅斑块。
- 染色时间不足：色浅且易掉色。
- 拆线过早：未固色就拆，纹理被污染。

## 安全与免责
- 染料、助剂需戴手套，避免接触眼睛；染液不可随意倒入下水道。
