# 赣绣上绷与起针步骤

## 一句话结论
刺绣上绷的顺序是：检查底布 → 放松绣绷 → 铺布 → 均匀绷紧 → 固定边缘 → 起针藏线。布面要“紧而不拉变形”，过松会起皱，过紧会把布纹拉歪。

## 材料与工具
- 底布、绣绷/绣架、绷布夹或针线固定、绣线、绣针、剪刀、小镊子。

## 操作步骤
1. **检查底布**：确认经纬正、无抽丝、无污渍；必要时先熨平。
2. **放松绣绷**：先把螺丝/卡扣松开，避免强行塞布。
3. **铺布**：把图案中心对准绣绷中心，先固定上下，再固定左右。
4. **均匀绷紧**：边拉边调，用手掌轻拍布面，确认没有局部过紧。
5. **固定边缘**：用绷布夹或临时针脚固定，避免缝线时布边回缩。
6. **起针**：从背面起针，先压线藏头，再按图案运针；收针同样在背面藏线。
7. **中途检查**：每完成一小块就检查布面张力，必要时重新调整。

## 常见失败
- 布面过松：针脚浮起、图案起皱。
- 局部过紧：布纹变形，拆绷后图案歪斜。
- 起针不藏线：背面线头外露，正面透色。
- 绣线过长：反复摩擦起毛、打结。

## 安全与免责
- 针和剪刀需妥善收纳；长时间低头注意颈肩休息。
- 本卡为教学步骤整理，具体上绷方式和针法以课程为准，待刺绣老师审核。
