# 剪纸与刻纸有什么区别

## 一句话结论
剪纸主要用剪刀在纸上连续剪出图形，线条连贯、边缘有剪口；刻纸用刻刀在垫板上逐刀刻制，适合多层、细密和大幅图案。两者都依赖起稿、叠纸和收刀，但工具、纸张和失败点不同。

## 对比表
| 维度 | 剪纸 | 刻纸 |
|---|---|---|
| 主要工具 | 剪刀（尖头、顺手） | 刻刀（不同刀尖）、蜡板/垫板 |
| 纸张 | 单层或少量叠纸 | 可多层叠刻，要求纸张平整 |
| 线条 | 连续、圆转，剪口明显 | 可做细密直线、镂空和复杂内轮廓 |
| 适合尺寸 | 中小幅、窗花、连环纹样 | 中大幅、精细纹样、批量复制 |
| 主要风险 | 剪口不齐、转折处断裂 | 刀尖跑偏、垫板划伤、手指受伤 |
| 入门难度 | 较低，但连续转折需练习 | 需要刀法和力度控制 |

## 适用与不适用
- 想做快速、手感强、边缘有剪味的小作品，选剪纸。
- 想做细密内部镂空、多层套色或批量复制，选刻纸。
- 两者都不适合用受潮起皱的纸；刻纸尤其要求纸面平整。

## 操作要点
1. 先画大轮廓，再处理内部小孔；顺序错了容易撕裂。
2. 刻纸从内向外、从细到粗，刀口垂直，不来回锯。
3. 叠纸层数不要一次加太多，先试刻两层确认能刻透。

## 安全与免责
- 刻刀和剪刀均为尖锐工具，需在明亮桌面操作，刀片及时更换并收纳。
- 本卡为教学对比；具体地域风格、历史与代表纹样待补权威来源并由非遗老师审核。

## 来源与审核
- 历史渊源、地域流派、代表性项目：待补非遗名录/地方志/学术资料。
- 审核状态：待非遗传承人或工艺老师审核；审核记录见 `docs/rag-corpus-register-20261123.md`。
