# 拼布与贴布绣有什么区别

## 一句话结论
拼布是把多块布片缝合拼接成一个大面，重点是结构连接；贴布绣是把裁好的布片固定/缝在底布上，重点是表面装饰。拼布可以没有贴布，贴布绣也不一定需要拼缝，两者常结合使用。

## 对比表
| 维度 | 拼布 | 贴布绣 |
|---|---|---|
| 主要目的 | 把碎布拼成面料/作品 | 在底布上形成图案 |
| 结构关系 | 布片之间是并列拼接 | 布片覆盖在底布之上 |
| 缝法 | 拼缝、压线、翻缝等 | 贴缝、锁边绣、藏针缝等 |
| 背面 | 常有拼缝余量，需熨平 | 背面可见固定线迹或衬纸 |
| 适合作品 | 被子、包袋、垫子、壁饰 | 图案装饰、补洞、局部点缀 |
| 难点 | 尺寸稳定、缝份一致 | 边缘毛边、布片起皱 |

## 适用与不适用
- 想消耗碎布、做结构性大面，选拼布。
- 想在成品上添加图案或修补遮盖，选贴布绣。
- 薄软布做贴布绣容易起皱，建议先加衬；拼布则要注意不同布料的缩水率。

## 操作要点
1. 拼布先统一缝份，按片编号，避免错位。
2. 贴布绣先把布片边缘做防脱散处理，再用细密针脚固定。
3. 两种工艺完成后都要熨烫定型，注意温度与布料匹配。

## 安全与免责
- 熨斗、针、剪刀有烫伤和扎伤风险；使用后及时断电收纳。
- 本卡为教学对比；传统拼布/贴布绣的历史与地域流派待补权威来源并由老师审核。
