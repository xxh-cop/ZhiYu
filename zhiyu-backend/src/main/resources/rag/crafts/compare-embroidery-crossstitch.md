# 刺绣与十字绣有什么区别

## 一句话结论
传统刺绣是在底布上自由运针，针法、方向、长短和配色都由图案需要决定；十字绣按网格数格，用统一的十字针填色，图案由像素化网格决定。前者自由度高、学习曲线长；后者规则清晰、容易上手，但风格受网格限制。

## 对比表
| 维度 | 刺绣 | 十字绣 |
|---|---|---|
| 运针方式 | 自由针法，可长短针、乱针、平绣等 | 基本为十字针，按格计数 |
| 图案来源 | 画稿/拓稿，可自由调整 | 网格图纸，按符号配色 |
| 表现力 | 细腻渐变、质感丰富 | 块面感强，边缘像素化 |
| 入门难度 | 需练针法和手劲 | 较低，但数格易错 |
| 返工成本 | 拆线可能伤布 | 拆错格相对容易定位 |
| 适合场景 | 装饰绣片、服饰、礼品 | 小幅挂画、书签、入门体验 |

## 适用与不适用
- 想做自由图案、渐变和材料混合，选刺绣。
- 想低门槛完成一幅规则图案，选十字绣。
- 两者都要注意底布经纬和线材色牢度；十字绣尤其要防止网格布变形。

## 操作要点
1. 刺绣先定针法顺序，避免反复穿刺同一孔。
2. 十字绣先找中心点，按区域推进，不要跨大片跳线。
3. 收针都应在背面藏线，避免正面露线头。

## 安全与免责
- 针、剪刀需妥善收纳；长时间低头注意休息。
- 本卡为教学对比；传统针法流派与历史待补权威来源并由刺绣老师审核。

## 来源与审核
- 历史渊源、针法分类、地域流派：待补非遗名录/教材/学术资料。
- 审核状态：待刺绣老师或非遗传承人审核；审核记录见 `docs/rag-corpus-register-20261123.md`。
