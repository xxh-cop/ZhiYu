# 陶土该怎么选

## 一句话结论
选陶土看“可塑性、收缩率、含砂量、烧成温度、是否适合目标成型方式”：手捏/盘筑选可塑性好的陶泥，拉坯选颗粒细、中心稳定的泥，做大件要加熟料/砂降低开裂风险。新泥先做试片，再定烧成曲线。

## 选型表
| 成型方式 | 适合泥料 | 优点 | 注意 |
|---|---|---|---|
| 手捏/盘筑 | 中粗陶泥 | 支撑好、易修 | 表面较粗，需打磨 |
| 拉坯 | 细陶泥/瓷泥 | 易定中心、壁薄 | 收缩大，干燥要慢 |
| 大件/板筑 | 含熟料/砂的泥 | 抗裂 | 表面粗，需化妆土 |
| 注浆 | 专用注浆泥 | 流动性好 | 需控制含水率 |

## 选择顺序
1. 先定成型方式，再选泥；不要用拉坯泥做大型板筑。
2. 问清烧成温度范围，泥和釉的成熟温度要匹配。
3. 做 10cm 试片：记录干燥时间、开裂、收缩、烧后颜色。
4. 新泥先小批量试用，确认手感和烧成效果再批量买。

## 常见误区
- 只看颜色：烧后颜色会变，试片才可靠。
- 泥越细越好：细泥收缩大，大件易裂。
- 不回泥直接用：干湿不均会导致夹层气泡。

## 安全与免责
- 陶土粉尘含硅，需防吸入；泥料不可入口，儿童需成人陪同。
- 本卡为选型建议，具体泥料参数以供应商检测报告和窑炉试烧为准；待陶艺老师审核。

## 来源与审核
