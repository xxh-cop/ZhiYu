# 剪纸起稿与下刀步骤

## 一句话结论
剪纸的稳定流程是：定主题 → 画大轮廓 → 安排连接点 → 由内向外剪/刻 → 修边 → 展开检查。新手最容易失败的不是“不会剪”，而是起稿时没有留连接点，导致图案散架。

## 材料与工具
- 纸张（平整、不过潮）、铅笔/橡皮、剪刀或刻刀、垫板、镊子、废纸练习。

## 操作步骤
1. **定主题**：先确定是窗花、人物、动物还是文字，控制单幅复杂度。
2. **画大轮廓**：先画外轮廓，再画内部镂空；线条之间要留“桥”，避免断开。
3. **标顺序**：从内部小孔开始，最后剪外轮廓；刻纸从细到粗、从内到外。
4. **试刀/试剪**：在废纸上确认力度，刻刀垂直下刀，不来回锯。
5. **修边**：用小剪刀修毛边，不要用力拉扯。
6. **展开检查**：轻轻展开，压平；断裂处用薄纸托底修补或重新设计连接点。

## 常见失败
- 连接点太细：展开即断。
- 线条交叉处反复剪：边缘起毛、纸层分离。
- 叠纸太厚：下层刻不透。
- 纸张受潮：下刀起皱、撕裂。

## 安全与免责
- 剪刀和刻刀为尖锐工具，需在明亮桌面操作；刀片钝了及时更换，不要用手直接清理碎屑。
