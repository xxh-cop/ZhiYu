# 扎染

## 历史渊源

扎染古称扎缬、绞缬，是中国传统的织物染色工艺之一，距今已有约两千年的历史。据记载，东晋时期绞缬工艺已相当成熟，至唐代大为流行。扎染通过捆扎、缝合、折叠织物后浸染，形成防染留白的花纹。云南大理白族扎染最为著名，江西地区的扎染在传统技艺基础上发展了本土纹样。2006年，白族扎染技艺被列入国家级非物质文化遗产名录。近年来，扎染作为手工体验项目在都市年轻人中重新流行，成为减压手作的代表。

## 工艺特点

扎染的核心在于"扎"与"染"两步。扎：用线绳、夹板、弹珠等工具将织物局部捆扎紧实，使被扎部位无法着色，形成留白花纹。染：将扎好的织物浸入染液（传统用板蓝根等植物染料，现代也用化学染料），通过多次浸泡、氧化获得深浅层次。扎染的魅力在于"不可控中的可控"——捆扎方式决定花纹大致形态，但染液的渗透程度受多种因素影响，每一次展开都是独一无二的惊喜。常见纹样有蝴蝶纹、梅花纹、波浪纹等，边缘自然晕染，色彩过渡柔和。

## 疗愈价值

扎染的捆扎过程充满触觉体验——手指缠绕线绳、感受织物质地，这种触感反馈有助于将注意力从内心纷扰转向手部操作。染色后的等待过程培养耐心，而展开织物的瞬间如同开盲盒般的惊喜感，能快速激活正向情绪。扎染的"不确定之美"帮助创作者接纳不完美——每一件作品都是独一无二的，没有"标准答案"。这种体验有助于缓解对完美的执念，培养灵活接纳的心态。扎染操作简单，适合零基础快速上手。

## 制作流程概要

扎染的基本流程包括：设计构图——在织物上画出花纹位置或直接凭经验捆扎；捆扎——用线绳、橡皮筋、夹子等工具按设计扎紧织物，松紧决定留白效果；配制染液——按比例溶解染料，调至所需浓度；浸染——将扎好的织物放入染液浸泡，时间长短决定颜色深浅；氧化——取出织物暴露于空气中氧化固色（植物染料需多次浸染-氧化循环）；拆线冲洗——拆开捆扎物，清水冲洗浮色至水变清；晾干——自然晾干或低温烘干。一件小型扎染作品约2至4小时可完成。
