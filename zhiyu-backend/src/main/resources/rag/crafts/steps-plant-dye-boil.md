# 植物染基础步骤：提取、染色与固色

## 一句话结论
植物染的基本顺序是：选植物材料 → 清洗/切碎 → 煮染液 → 过滤 → 浸湿织物 → 媒染（如需要）→ 染色 → 清洗 → 晾干。颜色深浅取决于植物用量、染液浓度、温度、时间和媒染方式，必须做小样。

## 材料与工具
- 植物材料（明确品种，避免未知有毒植物）、锅具（专用，不用于烹饪）、滤网、温度计、棉麻/羊毛等织物、媒染剂（按课程配方）、手套、废液桶。

## 操作步骤
1. **识别材料**：只使用可确认的植物；不确定的不要下锅。
2. **预处理**：清洗、切碎或浸泡，帮助色素释放。
3. **煮染液**：加水煮沸后转小火，按材料控制时间，过滤掉渣。
4. **浸湿织物**：均匀浸湿，挤去多余水分。
5. **媒染**：按课程要求先媒染或后媒染；媒染剂需单独容器、单独处理。
6. **染色**：控制温度和时间，适时翻动，避免局部过深。
7. **清洗晾干**：冷水洗去浮色，阴干；记录颜色变化。

## 常见失败
- 植物量不足：颜色太浅。
- 染液未过滤：布面沾渣。
- 媒染不均：色斑、色牢度差。
- 水质/锅具影响：颜色发灰或偏色。

## 安全与免责
- 植物种类、媒染剂和高温都有风险；“天然”不等于安全，未知植物不要使用。
- 本卡为教学步骤整理，具体植物清单和配方待工艺老师与安全负责人审核。
