# 蜡染基础步骤：绘蜡、染色与脱蜡

## 一句话结论
蜡染的基础顺序是：选布 → 起稿 → 熔蜡 → 蜡刀绘蜡 → 检查蜡层 → 入染 → 脱蜡 → 清洗晾干。图案成败主要看蜡温、蜡层厚度和绘蜡线条是否连续。

## 材料与工具
- 天然纤维布、蜂蜡/石蜡（按课程配方）、蜡刀、熔蜡器、温度计、染盆、手套、护目镜。
- 脱蜡用的加热容器和废蜡/废液收集容器。

## 操作步骤
1. **起稿**：用铅笔或可洗标记轻轻定稿，避免划伤布面。
2. **熔蜡**：隔水或专用熔蜡器加热，控制温度，避免冒烟或焦化。
3. **绘蜡**：蜡刀蘸蜡后先在废布上试温，线条要连续；需要冰纹的地方可让蜡层薄而均匀。
4. **检查**：透光看蜡层是否漏底，漏蜡处染色会渗入。
5. **入染**：按染料说明控制温度和时间，翻动要轻，避免蜡层开裂过多。
6. **脱蜡**：按规范加热脱蜡，废蜡集中处理，不倒入下水道。
7. **清洗晾干**：彻底清洗浮色，阴干。

## 常见失败
- 蜡温过高：蜡层焦化、布面发黄。
- 蜡温过低：蜡液渗透不足，防染失败。
- 线条断点：染色渗入形成意外色块。
- 冰纹过多：蜡层太薄或翻动过猛。

## 安全与免责
- 熔蜡和脱蜡涉及高温，必须在通风、防火环境操作；蜡液烫伤风险高。
- 本卡为教学步骤整理，具体蜡料配比和温度以课程为准，待工艺老师审核。
