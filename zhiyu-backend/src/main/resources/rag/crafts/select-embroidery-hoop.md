# 绣绷该怎么选

## 一句话结论
绣绷的选择按“作品尺寸、刺绣时长、底布厚度、是否需要连续运针”四项决定：小幅短时用圆形手绷，中大幅或长时间用方形/卷轴绷，布厚或易滑用带夹布条/螺丝锁紧的款式。没有一种绣绷适合所有作品。

## 选型表
| 维度 | 圆形手绷 | 方形/矩形绷 | 卷轴绷/绣架 |
|---|---|---|---|
| 适合尺寸 | 小幅、杯垫、胸针 | 中幅、图案集中 | 大幅、长卷、连续题材 |
| 布面张力 | 靠外圈压紧，边缘易松 | 四边可调，张力较均匀 | 卷轴拉紧，适合长时间 |
| 便携性 | 最好 | 一般 | 较差，适合固定工位 |
| 底布厚度 | 薄中厚均可，厚布需大号 | 厚布需加固边条 | 厚重布需确认卷轴承重 |
| 适合人群 | 入门、短时体验 | 进阶、系列作品 | 长时间创作、专业工位 |
| 注意 | 外圈太紧会压出印痕 | 四角易过紧，需轮换调整 | 卷轴直径影响可视区域 |

## 选择顺序
1. 先量图案最大宽度，绣绷内径至少比图案大 2–3 厘米，避免压住绣线。
2. 再看底布：薄软布选平整压边款，粗厚布选大号或带夹布条款。
3. 连续绣超过一小时，优先方形/卷轴绷，减少反复挪绷。
4. 入门先买一个中号圆形绷试手，确认自己会长期做再升级。

## 常见误区
- 越大越好：大绷对小幅图案反而难绷紧。
- 绷得越紧越好：过紧会拉歪布纹，拆绷后图案变形。
- 塑料绷一定比木绷差：关键看压合面和锁紧结构，不只看材质。

## 安全与免责
- 绣绷螺丝、夹口可能夹手；木质绷注意毛刺。
- 本卡为选型建议，具体品牌和型号不作推荐；待刺绣老师审核。

## 来源与审核
- 选型标准为通用教学整理，无商业背书；来源待补教材/工坊规范。
- 审核状态：待刺绣老师或非遗传承人审核；记录见 `docs/rag-corpus-register-20261123.md`。
