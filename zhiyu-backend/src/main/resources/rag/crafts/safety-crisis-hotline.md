# 危机时可以先联系谁：热线与转介口径

## 一句话结论
如果现在有伤害自己或他人的念头，先确保身边有人、远离危险物品，并立即联系可信任的人或专业热线；紧急危险拨打 110/120。线上问答不能替代紧急救援，也不能承诺保密。

## 可以立即做的四步
1. **离开危险物品**：把刀、剪刀、药物、绳索等放到自己拿不到的地方，或交给可信任的人保管。
2. **找一个人**：告诉家人、室友、老师或朋友“我现在状态很危险，需要你陪我”。
3. **联系专业帮助**：全国心理援助热线 12356；学校心理教育中心 0791-88120129（以应用内危机页实时配置为准）。
4. **紧急情况**：拨打 110/120，或直接前往最近医院急诊；不要独处等待。

## 沟通时可以怎么说
- “我现在有伤害自己的念头，需要有人陪着我。”
- “我不想一个人待着，你能不能现在过来/和我保持通话？”
- “请帮我联系学校心理中心或医院。”

## 不要做的事
- 不要承诺“我不会告诉任何人”——危机情况下需要联系可信任的人或专业机构。
- 不要用“想开点”“别矫情”否定对方感受。
- 不要让处于危险中的人独自离开。

## 安全与免责
- 本卡为危机口径草案，必须由危机干预负责人、咨询师与法务审核后才能发布；不构成诊断或治疗建议。
- 热线号码可能调整，始终以应用内危机页/官方公布为准；当前开发配置为 12356 与 0791-88120129。

## 来源与审核
- 热线与转介流程：待补机构书面授权与官方文件。
- 审核状态：待危机负责人与法务审核；记录见 `docs/rag-corpus-register-20261123.md`。
