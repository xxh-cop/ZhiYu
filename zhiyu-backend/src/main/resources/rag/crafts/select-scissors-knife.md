# 剪刀和刻刀该怎么选

## 一句话结论
剪纸/布艺的剪刀看“刃口长度、尖端、手柄顺手度、是否专用”；刻纸刀看“刀尖角度、刀片更换方式、握持稳定性、是否防滚”。不要用裁纸刀代替专业刻刀，也不要用剪纸剪刀剪硬物。

## 选型表
| 工具 | 适合场景 | 优点 | 注意 |
|---|---|---|---|
| 尖头小剪刀 | 剪纸内孔、修边 | 转向灵活 | 尖端易扎手，需收好 |
| 布艺剪刀 | 裁布 | 刃长、剪口齐 | 不要剪纸，会钝 |
| 美工刀/裁纸刀 | 直线裁纸 | 便宜、刀片可换 | 刀尖角度大，细节差 |
| 刻纸刀（笔式） | 精细镂空 | 刀尖细、易控制 | 需垫板，刀片钝了及时换 |
| 剪刀/刻刀套装 | 入门体验 | 成本低 | 质量参差，先试手感 |

## 选择顺序
1. 先定材料和动作：剪曲线用尖头剪刀，刻内孔用笔式刻刀，裁直线用美工刀。
2. 试握：手柄太细或太滑，长时间会磨手；左手使用者选对称手柄。
3. 看刀片：可替换刀片比一次性刀具更安全、更耐用。
4. 配垫板：刻纸必须有垫板，保护桌面和刀尖。

## 常见误区
- 一把剪刀剪所有材料：剪硬物会崩刃。
- 刀片钝了继续用：需要更大力度，反而容易跑偏受伤。
- 不看刀尖角度：角度越大越难做细部。

## 安全与免责
- 所有刃具都需在明亮桌面使用，刀口朝外，用完立刻收进刀套/笔帽。
- 本卡为选型建议，不推荐具体品牌；待工艺老师审核。
