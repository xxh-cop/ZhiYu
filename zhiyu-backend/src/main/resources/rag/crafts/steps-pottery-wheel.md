# 陶艺拉坯基础步骤

## 一句话结论
拉坯的基本顺序是：揉泥 → 定中心 → 开孔 → 提壁 → 修底 → 取坯 → 干燥 → 素烧/施釉/烧成。定中心是第一步也是最重要的一步，中心不稳，后面越拉越歪。

## 材料与工具
- 练好的陶土、拉坯机、水盆、海绵、割线、修坯刀、托板、湿度控制环境。

## 操作步骤
1. **揉泥**：排出气泡，避免烧成时炸裂；泥团软硬均匀。
2. **定中心**：泥团放在转盘中心，双手夹稳，低速把泥团压成同心圆。
3. **开孔**：拇指从中心下压，留出底厚，不要一次压穿。
4. **提壁**：双手内外配合，从底部向上分次提拉，每次少量，保持壁厚均匀。
5. **修口**：收口或翻边，控制口沿厚度。
6. **取坯**：用割线从底部脱离，托板转移，避免捏变形。
7. **干燥**：缓慢阴干，厚薄交界处最容易开裂。
8. **后续**：按课程安排素烧、施釉、烧成。

## 常见失败
- 中心不稳：坯体偏心、壁厚不均。
- 一次提太高：泥壁塌陷。
- 加水过多：泥变软、无法成型。
- 干燥过快：开裂、变形。
