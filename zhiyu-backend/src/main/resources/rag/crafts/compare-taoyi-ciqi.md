# 陶艺与瓷艺有什么区别

## 一句话结论
陶与瓷的核心差别在原料、烧成温度和胎体致密度：陶器多用普通黏土，烧成温度相对较低，胎体较疏松、吸水率较高；瓷器用瓷土/高岭土类原料，烧成温度更高，胎体更致密、吸水率更低，常配釉。两者都要经历成型、干燥、烧成，但工艺窗口不同。

## 对比表
| 维度 | 陶艺 | 瓷艺 |
|---|---|---|
| 原料 | 陶土/黏土，颗粒较粗 | 瓷土、高岭土等，含铁量通常更低 |
| 烧成 | 温度相对较低，气氛影响大 | 温度更高，胎体玻化程度更高 |
| 胎体 | 较厚、较疏松，吸水率较高 | 较薄、致密，吸水率低 |
| 釉 | 可不施釉或低温釉 | 常施高温釉，釉色与胎体配合要求高 |
| 声音/手感 | 敲击声较沉，手感温厚 | 敲击声较清，手感细腻 |
| 难点 | 干燥开裂、变形 | 高温烧成收缩、釉面缺陷控制 |

## 适用与不适用
- 想做厚实、质朴、手感强的器皿，陶艺更合适。
- 想做轻薄、致密、釉色细腻的器物，瓷艺更合适。
- 两者都需要稳定的干燥和烧成条件；没有窑和排釉条件的场景不适合直接开展。

## 操作要点
1. 成型后必须缓慢干燥，厚薄不均最容易开裂。
2. 施釉前确认胎体清洁、无粉尘；釉层厚度要试片验证。
3. 烧成曲线按泥料和窑型设定，不能照搬别人的温度。

## 安全与免责
- 粉尘（尤其含硅原料）需防吸入；釉料和助剂不可入口，作品是否可食用需按釉料安全标准确认。
- 本卡为教学对比；具体原料、温度与历史流派待补权威来源并由陶艺老师审核。

## 来源与审核
- 历史渊源、窑口与地域流派：待补权威来源（非遗名录/博物馆/学术资料）。
- 审核状态：待陶艺老师或非遗传承人审核；审核记录见 `docs/rag-corpus-register-20261123.md`。
