# 赣绣与夏布绣有什么区别

## 一句话结论
两者都属江西地方刺绣实践，但常用底布和质感不同：赣绣是一个地域性统称，常以丝线在绸、棉等底布上施针；夏布绣以夏布（苎麻织物）为底，布面粗粝、纹理明显，针脚和图案要顺应布纹。

## 对比表
| 维度 | 赣绣（地域统称） | 夏布绣 |
|---|---|---|
| 底布 | 绸、棉、麻等，按具体项目而定 | 以夏布为主，布纹粗、孔隙明显 |
| 线材 | 丝线、棉线等 | 丝线/棉线均可，需考虑粗布摩擦 |
| 视觉质感 | 细腻、光泽取决于线材 | 质朴、肌理强，图案与布纹互相影响 |
| 针法选择 | 平绣、乱针等按题材选择 | 需减少长针、避免勾丝，常用较稳的短针 |
| 难点 | 针法层次与配色 | 底布粗硬、易磨线，起针和收针要稳 |
| 适合入门 | 取决于具体针法 | 需要先练习在粗布上均匀运针 |

## 适用与不适用
- 想表现细腻渐变、人物花鸟，通常更适合细密底布和丝线。
- 想突出材料本身的粗粝质感、做小幅装饰，夏布绣更合适。
- 两者都需要先确认底布缩水率和线材色牢度；未测试就大幅创作容易返工。

## 操作要点
1. 夏布先熨平、试针，必要时加衬布减少变形。
2. 线不要太长，减少反复摩擦起毛；收针藏线要牢固。
3. 图案边缘避开布面大孔，防止针脚被拉脱。

## 安全与免责
- 针、剪刀属于尖锐工具，需在明亮环境使用并妥善收纳。
- 本卡为教学对比；具体流派、历史与代表性针法待补权威来源，并由传承人审核。

## 来源与审核
- 历史渊源、地域范围、代表性项目：待补非遗名录/地方志/学术资料。
- 审核状态：待非遗传承人或工艺老师审核；审核记录见 `docs/rag-corpus-register-20261123.md`。
