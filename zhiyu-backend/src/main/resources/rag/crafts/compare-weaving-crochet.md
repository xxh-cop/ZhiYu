# 编织与钩织有什么区别

## 一句话结论
编织通常指用两组或多组线材按经纬（或串套）关系交织成面，常见竹编、草编、毛线棒针编织；钩织只用一根钩针，把线不断拉成线圈并相互串套。两者成形原理、工具和结构弹性不同。

## 对比表
| 维度 | 编织 | 钩织 |
|---|---|---|
| 工具 | 棒针、梭、竹篾等，按材料而定 | 单根钩针 |
| 成形 | 经纬交织或成行串套 | 线圈连续串套，可环形起针 |
| 结构 | 较稳定，边缘需收口 | 弹性较大，可立体成形 |
| 常见材料 | 竹、草、毛线、棉线 | 毛线、棉线、蕾丝线 |
| 修改难度 | 拆行较难，尤其竹草编 | 可拆到任意线圈重来 |
| 适合作品 | 平面织物、器物、筐篮 | 玩偶、花朵、包袋、立体件 |

## 适用与不适用
- 想做承器、平面结构或材料编织，选编织。
- 想做立体小物、快速成型、易拆改，选钩织。
- 两者都要先确认线材粗细与工具匹配，否则成品松紧不均。

## 操作要点
1. 编织先起底/起针，确认经纬或针数正确再推进。
2. 钩织先练锁针、短针、加针减针，再上复杂花样。
3. 每完成一段就检查尺寸，避免到最后才发现密度不对。

## 安全与免责
- 竹篾、棒针、钩针都可能造成扎伤，需注意工具收纳和用眼休息。
- 本卡为教学对比；具体传统编织流派与历史待补权威来源并由老师审核。

## 来源与审核
- 历史渊源、地域流派、代表性项目：待补非遗名录/地方志/教材。
- 审核状态：待工艺老师或非遗传承人审核；审核记录见 `docs/rag-corpus-register-20261123.md`。
