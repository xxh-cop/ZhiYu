## 2. 非劣性检验（L3 漏放率，单侧 95%，δ=5pp 目标）

实测关闭臂基线 p0 = 7.65%（14/183），开启臂 p1 = 3.24%（6/185）：

| 量 | 值 | 说明 |
|---|---|---|
| 点差（on − off） | **−4.41pp** | 开启臂更低 |
| 差值单侧 95% 上界 | **−0.53pp** | < 0 且 < δ=5pp → 按非劣性检验口径**可宣称非劣** |
| 差值双侧 95% 上界 | +0.21pp | 跨 0——双侧口径下差异不显著（如实并列） |
| McNemar 配对（b/c） | **8 / 1** | 8 条 OFF 漏放脱离放行（3 转拦截、5 转关注）、1 条新增漏放（crisis-p90，见 §4） |
| **实测基线下守 5pp 所需样本量** | **350/臂** | (z₀.₀₅+z₀.₈)²·2p₀(1−p₀)/δ²，p₀=7.65% |
| **现 n（183/185）实际可守的界** | **≈5.9pp** | 同一公式反解 δ；**守不住 5pp 预设界** |

**Biostat 口径结论**：点估计与单侧检验支持「非劣（δ=5pp）」，但**设计功效不足**——
在实测基线 7.65% 下，186 条/臂只能守约 5.9pp 的界，守不住 5pp；
且差值双侧 95% 区间跨 0、McNemar 仅 9 个不一致对。**结论写为：方向证据支持非劣，
功效不足以作正式非劣宣称**（「功效不足、无法判定」为更稳的读法）。

## 6. 这个基线能不能支撑开启软档

**不能（维持既有门槛判断）**，但差距已显著收窄。理由与缺口：

1. **硬前置未变**：抽检池、曝光降权、SLA、回流仍未实现（本轮只评不测），
   软档处置为空转——这是与统计无关的一票否决。
2. **统计上**：误杀改善（43pp）与干净放行提升（16.7pp）证据充分；L3 非劣在单侧口径过线、
   但设计功效不足（守 5pp 需 350/臂，现 183/185，实际可守约 5.9pp），且有 p90 单点回摆、
   p180 降级带来的有利方向不确定性。
3. **最小补样**：非劣性宣称最省的补法是**只补 L3 组**——按实测基线补到 350/臂，
   每臂再补 **约 165 条 L3 样本（两臂约 330 次调用）**；良性/边界组样本量已远超所需，不必补。
4. 模型/时间维度仍未覆盖：单窗口、单模型（deepseek-reasoner）、仅文本，结论外推需复跑机制
   （harness 已支持断点续跑与 id 清单驱动）。
