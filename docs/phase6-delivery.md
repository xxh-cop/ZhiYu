| 社区视频 | 学生可选择视频、查看上传进度、取消或重试、预览并提交；视频作品先审核再公开，管理员可预览、批准或下架。 |
| 视频存储 | 采用本地私有目录，预留 MediaStorage 接口供对象存储接入；新视频通过有时效的签名地址播放，并逐次复核当前访问权限。 |
| 数据库 | 增量迁移新增 craft_project.video_url 和 media_asset；同步标准建表文件、测试库、接口契约和启动兼容检查。此前 work.media_type 缺失修复继续保留。 |

音乐定位为自愿的放松活动，不承诺治疗效果。视频目前限制 MP4、每文件最大 50MB、每用户每天最多 20 次上传；建议使用 H.264 + AAC。现有文件头校验不等同于完整解码、病毒检测或转码。

## 企业级水平评估与后续优先级

当前已具备校内试用的功能基础，界面、审核和权限流程比单纯展示型原型更完整；尚不能据此宣布达到企业生产验收标准。

1. **试用前配置与验收**：部署 HTTPS、生产密钥、真实机构联系资料、备份恢复与告警；小程序 API 地址需要改为可访问的局域网或正式域名并配置合法域名。当前 localhost 仅适用于本机开发。完成微信/iOS/Android 真机播放、弱网、后台切换、不同编码视频和可访问性验收。
2. **媒体服务**：接入对象存储、断点续传、转码与封面、字幕、内容检测、上传并发配额、孤立文件定期清理与保留期限。新视频受私有访问控制；历史 uploads 文件不自动获得同样保护，需要单独迁移审计。
3. **内容与运营**：建立真实传承人课程、阶段成品照片、材料清单和字幕；逐步扩充有完整授权证据的音乐。当前两首音乐、三张品类照片属于首批内容，不能代替完整内容库。
4. **教学体验**：在真实课程基础上增加视频章节与步骤定位、进度恢复、材料替代建议、反馈与课程纠错；先根据学生试用数据验证需要，避免堆叠入口。
5. **可靠性与治理**：进行并发压测、独立权限审查、审核操作追踪及备份演练；图表继续坚持真实数据与清晰口径，不以演示数字充实页面。上线隐私文案需与实际部署及删除机制逐项核对。
