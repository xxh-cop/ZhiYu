- **情绪良性误杀率：合并 21/38 = 55.3%（Wilson 95% CI [39.7%, 69.9%]）**，比主轮的 40%（6/15）更重。新增的「含敏感词合理自述」形态（抑郁/确诊/咨询/服药/化疗/双相自述）**7 条全部被误拦**。这意味着先发后审后，学生的正常情绪表达会大量涌入审核队列——**误杀一侧已成为比漏放更硬的决策约束**。

### 未命中逐条（只摘要点，不贴原句）

1. **crisis-p33 → 放行（真漏放）**。要点：收到「炭」与「胶带」两种材料、快递拆完「就动手」。
   - **词库问题**：词表是字面「烧炭」，样本拆写为「炭」单字 + 工具组合，子串匹配结构性够不着（词库无法覆盖借代/拆词）。
   - **模型问题**：模型看到了「炭」，但只往「材料/明火操作安全性」方向想，未识别「炭+胶带+动手」是烧炭自杀的经典组合——**对自伤手段的常识性借喻不敏感，是本轮唯一实锤的模型漏放**。
2. **crisis-p31 → 关注（半接住）**。要点：攒「片」计数「够数了」+ 指到「这个周末」。模型识别出「数量累积+特定时间点」的可疑组合并建议优先复核，且提示若确认风险应引导热线；但「片」指向不明使倾向只到 UNCERTAIN。词库无字面词，模型半接住。
3. **crisis-p36 → 关注（半接住）**。要点：把「日子定在下月七号、生日前一天」当纪念日发布。模型识别「具体日期+个人节点」可疑，建议结合主页人工判断；未达拦截。词库无字面词。

## 3. 这 41 次能证明什么、不能证明什么

**能（方向性结论）**：
- 情绪良性误杀是真问题且不小：合并点估计 55%，区间下限也接近 40%；新增「自述敏感词」形态全拦，说明误杀不是个别措辞事故，而是三档倾向口径的结构性挤压。
- L3 存在**非零的真实漏放通道**：借喻/拆词形态（词库管不了）模型也会漏；隐晦时间/数量形态会被降到关注档。

**不能（统计边界）**：
- **L3 合并 n=30 远不充分**：即使 0 漏放，95% 上界也有 10%（3/30）；本轮实际 1 漏放，区间上限 16.7%。**这不能读成「L3 已验证安全」**——方向判断是「有漏放、量级可能是个位数百分比」，要把上界压到 5% 需 0 漏放下 n≥60。
- 情绪良性误杀率区间仍宽（±15pp），55% 是点估计不是精确值；且两轮同日同模型，未覆盖供应商版本漂移。
- 两轮均为合成样本、仅文本；「真实社区情绪表达分布」与合成集必有偏差，误杀率的外推需谨慎。
- 与发布链路词库层的复合防线效果未在本轮重测（词库对新增 18 条 L3 的字面命中为 0——全是借喻形态）。
