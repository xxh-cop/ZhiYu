# 手作项目难度分级口径（2026-11-05 定稿）

本文档是 `craft_project.level` 的**唯一判级依据**。定级必须可由第三人按本文档复算，不允许拍脑袋。

## 1. 字段语义与取值域

`craft_project.level TINYINT NOT NULL DEFAULT 1`：**1 入门 / 2 进阶 / 3 高阶**。取值域全链路一致：`sql/schema.sql` DDL 注释、`openapi/openapi.yaml`、学生端 `levelLabel`（recommend.vue / detail.vue / inheritor/detail.vue）、管理端 `status-dict.ts` PROJECT_LEVEL 与 `project-edit.vue`。**当前不支持第 4 档**；扩档需同步 DDL 注释、契约、两端文案与字典，另行立项。

写入端校验：`ProjectCreateDTO.level` 为 `@NotNull @Min(1) @Max(3)`；`ProjectUpdateDTO.level` 可空（不更新）但非空时同样 `@Min(1) @Max(3)`；越界返回 HTTP 400 + `code=1001`。

### 同名 level 的口径区别（勿混淆）

| 字段 | 类型/取值 | 语义 | 消费方 |
|---|---|---|---|
| `craft_project.level` | TINYINT 1/2/3 | **项目难度**（本文档） | 推荐过滤与排序、看板 byLevel、两端展示 |
| `craft_safety.level` | VARCHAR LOW/GUIDED/HIGH | **材料/工具安全等级** | 推荐安全过滤（maxSafety）、学生端材料页 |
| heritage pattern `level` | 字符串 入门/进阶 | 非遗纹样**练习节奏** | practice 模块 AdaptivePracticeService |

已知命名风险：`GrowthService` 的安全信息接口把 `craft_safety.level` 以字段名 `level` 输出（未标注时 `UNKNOWN`），与项目难度同名不同义。**本次只记录，不改名**（属契约变更，另行处理）。

## 2. 判级三维度与阈值

判级只看三件事；**工具风险不参与定级**——风险≠难度，安全等级已由 `craft_safety.level`（LOW/GUIDED/HIGH）独立承载并在推荐链路单独过滤，混用会导致「危险但简单」或「安全但复杂」的项目被错标。

| 维度 | 数据来源 |
|---|---|
| A. 估时 | `craft_project.est_minutes` |
| B. 工序可逆性 | 步骤引导文案：错了能否重来/补救（浸染定型、剪断连接处、贴合成型为半不可逆） |
| C. 认知/动作负荷 | 步骤引导文案：是否需持续规则追踪（多色交错、起始方向相反）或精细控制（穿针、藏线头）；是否多材料复合工序 |

**档位阈值**：

- **L1 入门**：估时 ≤20min；每步可重来或有明确补救；动作单一重复。
- **L2 进阶**：满足任一——估时 >20min；含半不可逆工序；需持续规则追踪或精细控制；多材料复合工序。
- **L3 高阶**：估时 >60min；或多工艺复合需依次成型；或需专用设备/热源/烧制/明火。

> L3 当前**保持空缺**：种子内容全部为入门设计，按上述标准无一达到 L3。这是标准一致的结果，不为凑看板分布拔高任何项目。L3 留给传承人后续真实高阶内容。

## 4. 数据缺口（定级时如实标注）

- **104**：0 步骤、0 材料、0 安全行，唯一无法复算的项目；补齐内容后按本文档复核。
- **101–103**：无 `craft_material` / `craft_safety` 行；器具判断来自 intro/步骤文案推断。
- B/C 两维度本质为文案判读，复核时按本文档阈值逐条对照即可复算。
