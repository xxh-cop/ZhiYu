# 织愈 · UI 规范（v0.1）

> 适用范围：`zhiyu-admin/`（Vue3 + Element Plus）与 `zhiyu-app/`（UniApp 学生端，H5 / 微信小程序）。
> 本文件由 T0.6a 建立，是两份前端工程**唯一**的色板与度量来源。
> 落地方式：
> - 管理端：`zhiyu-admin/src/styles/variables.scss`（SCSS 变量）→ `zhiyu-admin/src/styles/index.scss`（CSS 自定义属性 + Element Plus 主题覆盖）
> - 学生端：`zhiyu-app/src/uni.scss` 末尾追加同名变量，值必须与管理端一致。

## 1. 色板

| 名称 | 值 | 用途 |
|---|---|---|
| 主色 · 茶褐 | `#8B6F47` | 主按钮、选中态、链接、Logo |
| 背景 · 米白 | `#F7F4EF` | 页面背景、导航栏背景 |
| 文字主色 | `#2B2B2B` | 标题与正文 |
| 强调色 · 暖驼 | `#C89B6E` | 次级强调、标签、图表辅色 |
| 边框 | `#E5DDD0` | 卡片描边、分割线、输入框静默描边 |
| 危险 | `#B85450` | 删除、驳回、错误提示 |

补充：
- 辅助文字（说明、占位）用 `#8A8378`，更弱的提示用 `#A49C90`。
- 卡片白底用纯白 `#FFFFFF`，与米白背景形成层次。
- **疗愈主题底线**：不使用高饱和红、纯黑或大面积纯白铺底；错误态用偏灰的 `#B85450`，不用 `#FF0000`。

## 2. 字体

| 层级 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 22px | 600 |
| 区块标题 | 18px | 600 |
| 正文 | 15px | 400 |
| 辅助文字 | 13px | 400 |

- 行高统一 `1.6`。
- 字族：`'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif`。

## 3. 间距

基准 4px；实际只使用以下 5 档：

| 值 | 用途 |
|---|---|
| 8px | 图标与文字之间、卡片内文字与数值 |
| 12px | 表单项内部、按钮组 |
| 16px | 卡片内边距、表单项之间 |
| 24px | 卡片之间、区块之间 |
| 32px | 页面主内容区外边距 |

## 4. 圆角

| 元素 | 值 |
|---|---|
| 卡片 | 12px |
| 按钮 / 输入框 | 8px |

## 5. 阴影

全局只用一种阴影：

```
box-shadow: 0 2px 8px rgba(139, 111, 71, 0.08);
```

（主色 8% 透明度，保持"纸上浮起一层"的轻柔感，不使用大面积深阴影。）

## 6. 无障碍与文案红线

- 正文与背景对比度 ≥ 4.5:1（`#2B2B2B` on `#F7F4EF` 满足）。
- 涉及心理的页面必须出现「本系统不能替代专业心理咨询」声明。
- **禁止**诊断性措辞：「抑郁症」「焦虑症」「你患有」等一律不得出现在任何界面（含错误提示、占位文案）。
