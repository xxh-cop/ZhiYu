# 织愈集中交付清单（2026-10-20）

承接需求审阅与业务交付记录中的缺口。以下“完成”指本地实现与所列验证完成，不表示企业生产环境已验收。

## 本轮完成范围

- [x] 注销清理：清空个人资料及私密正文，撤下作品、移除互动、取消预约和主办活动、退出小组；停用或注销组长时交接给有效成员，无成员则关闭。写请求与注销以数据库用户行锁协调；SSE 持久化独立校验账号。
- [x] 媒体清理：本人私有媒体撤权后进入持久化队列，每分钟尝试清理，失败保留重试；旧公开图片仅处理能关联本人且没有其他有效引用的合法路径。
- [x] 个人副本：16 类个人数据分页导出，新增创作会话、学习进度、小组关系、本人交流消息、评论、收藏和媒体清单；受保护图片、视频另有原文件保存入口。
- [x] 预约交流：已确认预约由学生单独开启；仅双方访问，管理员无旁观权限；安全过滤、加密保存、分页历史、作者撤回。关闭授权或取消预约后只读；重新预约需要重新开启。
- [x] 小组协作：仅组员可见的作品墙、图片与视频授权；退出小组后旧签名链接重新鉴权。结伴邀请由接收者同意，双方可取消，退出后关系取消；邀请列表排除本人。
- [x] 活动协作者：主办人分配有效带领者；协作者可管理课程及签到，不能再次授予权限；一对一预约不开放协作授权。
- [x] 运行配置：管理员调整推荐数量、排序权重、材料安全范围、模型参数和提示扩展；修订号防止覆盖他人修改。安全模板不可替换，配置不承载密钥；未知或高风险材料不进入自动推荐。
- [x] 情绪续聊：历史会话恢复、主动结束、保存安全处理后的结束内容；作品寄语读取本人关联会话上下文。历史读取失败时独立重试，并暂停发送。
- [x] 内容分享：手作与活动入口接入 H5 复制、微信主动分享；登录后恢复白名单内目标。社区原有分享与权限控制继续保留。
- [x] 管理操作与看板：管理写操作记录执行者及动作，不记录私人请求正文；分类、审核状态、活动类型图表联动真实列表，另有可键盘操作的入口。项目列表补齐难度与时长。
- [x] 放松与纹样：音乐保持主动播放、定时停止、离页暂停及来源署名；增加可随时停止的 4 秒吸气 / 6 秒呼气练习。提供六份原创开放纹样，按类型与难度选择。
- [x] UI 收尾：延续双端松绿主题与小织；预约交流宽屏双列、手机单列；新增业务按钮使用可访问组件，完善状态、重试、提交锁定及选中语义；工作台优先呈现审核、关怀和预约入口。修复管理端生产配置误指向模板演示服务的问题。
- [x] 契约与交付：新增表写入规范 DDL、H2 结构、增量迁移；接口契约补齐唯一操作标识；新增业务 Gherkin 场景；README、隐私页与文档更新到实际行为。
