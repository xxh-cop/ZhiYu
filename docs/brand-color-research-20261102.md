## 1. 结论先行

**推荐方案 A「青玉案」（`#217E76` 族），理由三条，按权重排序：**

1. **品牌同源**：`#217E76` 已经是织愈 logo 交织双线的官方色（brand-assets.md），
   选它等于把「四个主色并存」的现状直接收敛到唯一事实源，而不是再发明第五个。
2. **对比度全绿**：主色白字按钮 4.87:1、正文 10.89:1、深色态 14.14:1，关键组合全部过 WCAG AA，
   是三套里唯一不需要为可用性打补丁的方案。
3. **迁移成本最低**：学生端现行薄荷青 `#2D9B8F` 是它的亮阶，管理端 indigo 换成它即可；
   方案 B/C 都要推翻学生端全部既有视觉认知与小织形象配色。

方案 B（敦煌矿物）非遗叙事最漂亮，但石绿偏冷、土黄文字不达标，且「像文创展陈，不像日常陪伴工具」；
方案 C（暖陶）最温暖，但推翻全部既有资产，陶土色在管理端数据密度下显脏。**B 的赭金被吸收进 A 的点缀层，C 不推荐。**

## 2. 参照项目配色（8 例）

> 「查证」= 本次联网检索到明确来源；「经验判断」= 基于公开认知，未逐一验证；「未查证」= 没找到可靠色值。

| 项目 | 类别 | 主色 | 辅助/氛围 | 来源性质 |
|---|---|---|---|---|
| Calm | 心理疗愈 | `#1B2250` 午夜蓝（primary） | 渐变蓝 `#5BA3EC`、白；氛围：夜空、睡眠、深沉安静 | 查证（mobbin/screenspo 品牌色分析） |
| Headspace | 心理疗愈 | 橙 `#F06E1D`（logo 圆点） | 深李紫、黄 `#FFCE00`；氛围：活泼、去神秘化、亲和 | 查证（官方 Partner Brand Guidelines PDF） |
| BetterHelp | 心理服务 | 主绿 `#397A4A` | 深绿 `#184C3D`、浅绿 `#96E092`、青 `#7BD1CF`；氛围：自然、可靠 | 查证（官方 Brandbook PDF） |
| 潮汐 Tide | 冥想专注 | 牛仔蓝 `#3a5fa1` | 午夜蓝 `#0C1A32`、翠绿 `#48B85B`；氛围：极简、自然声景 | 半查证（screenspo 第三方分析） |
| Woebot | AI 心理陪伴 | **未查证**到可靠色值 | 官网以浅蓝紫插画为主（经验判断，不采信为数据） | 未查证 |
| 故宫博物院 | 传统文化 | 城墙红（VI 手册官方确认色相） | 黄瓦金；氛围：庄重、历史 | 查证色相，**HEX 未查证**（网传 `#9E1F32` 等版本不一，不采信） |
| 敦煌壁画 | 传统文化 | 石绿 `#2C9678` | 土黄 `#D6A01D`、赭石 `#955539`；氛围：矿物质感、文明交汇 | 查证（敦煌配色色卡 + in5.cn 中国传统色） |
| Etsy | 手作社区 | 橙 `#F1641E` | 白底 + 米色系店铺氛围；温暖、手作、非企业感 | 查证（多个 logo 资料站一致） |

**规律**：心理疗愈类两极分化——要么深静（Calm/Tide 的夜蓝），要么暖活（Headspace/Etsy 的橙）；
绿色系（BetterHelp）兼取「自然+可靠」。传统文化类以矿物色（石绿/赭石/土黄）讲故事。
织愈的定位是「日常陪伴 + 非遗手作」，既不能学 Calm 的夜蓝（太冷太睡眠向），
也不能学 Headspace/Etsy 的亮橙（太兴奋，与「平复」目标相反）——**绿青系 + 暖金点缀**是空档也是正解。

## 3. 三套候选方案

### 方案 A · 青玉案（推荐）

| 角色 | 色值 | 关键对比度（实算） |
|---|---|---|
| 主色 | `#217E76` | 白字按钮 **4.87:1 ✓**；白底链接 **4.87:1 ✓** |
| 主色亮阶（深色态主色/选中态） | `#5BC4A8` | 深底 `#14201C` 上 **7.91:1 ✓** |
| 点缀暖金（仅图形/徽章） | `#D9A441` | 不作文字用（2.89:1 不达标，限定装饰） |
| 深金文字（引用/非遗标注） | `#8A6D1F` | 底上 **4.54:1 ✓** |
| 页面底 / 卡片 | `#F5F7F2` / `#FFFFFF` | — |
| 正文 / 次要 | `#233D34` / `#4A5F54` | **10.89:1 ✓** / **6.37:1 ✓** |
| 成功 | `#2E7D5B` | 4.63:1 ✓ |
| 警示 | `#9A6A12` | 4.38:1（大字/图标级；正文级警示文案用深金） |
| 危机干预（非纯红） | `#A64842` 绛 | 白底 5.79:1 ✓；白字按钮 5.79:1 ✓ |
| 深色态：底 / 文字 | `#14201C` / `#E8EDE9` | **14.14:1 ✓** |

应用感觉：对话气泡 assistant 侧白卡+深青文字，用户侧浅青 tint；主按钮深青白字；
首页氛围是「雨后竹林」而非「医院走廊」。与现行学生端无缝衔接（亮阶即现 `#2D9B8F` 家族）。

### 方案 B · 敦煌矿物

| 角色 | 色值 | 关键对比度 |
|---|---|---|
| 主色 石绿（深化） | `#1F7A63` | 白字 **5.22:1 ✓** |
| 辅助 赭石 | `#955539` | 米底上 **5.25:1 ✓** |
| 点缀 土黄（文字级深化） | `#A67A12` | 3.53:1（仅大字/图标） |
| 页面底 / 卡片 | `#F7F4EC` / `#FFFDF8` | — |
| 正文 / 次要 | `#2E2A24` / `#5C554A` | **12.97:1 ✓** / **6.70:1 ✓** |
| 深色态：底 / 石绿亮 | `#1C1A15` / `#4FB08F` | 文字 **14.37:1 ✓** / 主色 6.57:1 ✓ |

应用感觉：像「可以每天用的敦煌展」。问题：暖米底+矿物色偏「展陈感」，
对话场景温度够但清爽度弱；土黄警示不达标需深化；与现有薄荷青资产断裂。

### 方案 C · 暖陶杏雨（不推荐）

| 角色 | 色值 | 关键对比度 |
|---|---|---|
| 主色 陶土 | `#B05C3C` | 白字 4.73:1 ✓ |
| 辅助 青瓷 | `#4E7E76` | 白字 4.60:1 ✓ |
| 页面底 / 正文 | `#FAF6F1` / `#33291F` | 13.21:1 ✓ |
| 深色态：底 / 陶亮 | `#221A13` / `#D89A78` | 文字 14.40:1 ✓ / 主色 7.19:1 ✓ |

不推荐的原因：推翻全部既有视觉资产与小织配色；陶土主色在管理端表格/图表的数据密度下显脏；
暖色主导与「平复情绪」的目标有张力（暖色提高唤醒度）。仅建议在「完成庆祝」等单点场景借其杏色。

## 4. 明确避开的坑

1. **医院感冷蓝白**：纯白 `#FFFFFF` 铺底 + 冷蓝主色（如 `#3A7BD5` 系）会立刻医疗化，
  与「非诊断陪伴」红线冲突——三套方案全部用暖白/米白底规避。
2. **焦虑感饱和红**：纯红 `#FF0000`/`#E53935` 禁止出现在任何状态（含错误态）；
  危机干预统一用降饱和绛红（A 方案 `#A64842`），既有警示性又不制造恐慌。

## 5. 与现有资产的衔接判断

| 方案 | 对 `theme.scss` 珍珠玻璃令牌 | 对 ui-guidelines 现有色板 | 对 logo/小织 |
|---|---|---|---|
| A 青玉案 | **可延续**：`--zy-glass-*` 全部从 `hsl(var(--x)/a)` 派生，换主色即自动跟随 | **需演进**：四色收敛为一族，tokens.json 扩容 | 同源，零改动 |
| B 敦煌矿物 | **需演进**：玻璃层可留，环境光三色（indigo 蓝、success 绿）要重配 | **要替换**：底色、文字色全换 | logo 需重配色，小织衣服撞色 |
| C 暖陶杏雨 | **要替换**：玻璃高光在暖底上发灰，需重做内高光色 | **要替换** | 全部推翻 |

## 6. 需要用户做的选择

1. **主决策**：A / B / C 选哪套？（建议 A；若想保留 B 的非遗叙事，A+赭金点缀已覆盖八成效果）
2. **附带决策 1**：若选 A，警示色接受「大字/图标用 `#9A6A12`，正文级用深金 `#8A6D1F`」的双轨处理吗？
   （另一选择是把警示再加深到 `#8A5F0F`，牺牲一点辨识度换全场景 AA）
3. **附带决策 2**：暖金 `#D9A441` 接受「仅图形、不作文本」的约束吗？（现状 audit 已指出旧
   `#FFB547` 类似问题，这是延续性修正）
