## 已实现

- 浅青玉梨形布偶、柔软不对称线环、干净五官、奶油布贴与两枚装饰金针脚、松心形线尾。布贴是手作装饰。
- `zhiyu-app/src/static/mascot/xiaozhi-*.png`：标准、陪伴、倾听、思考、手作、完成、休息七张 384×384 透明图；独立重画的头像为 144×144，供 48px 及以下入口使用。
- 新 PNG 共 302,553 字节（约 295.5 KiB），原八张旧图共 336,294 字节。已移除打包目录中的旧 `xiaotuan-*.png`，历史 `asset-archive` 不参与打包。
- `XiaotuanPet.vue` 保留现有调用名、尺寸、face 和 open 事件，统一替换所有使用该组件的首页、聊天、作品、隐私、账号与活动等入口。`EmptyArt.vue` 的旧内嵌线团也已替换。
- 首页欢迎使用挥手造型，手作步骤使用绣绷造型，暂停时安静休息，完成时展示布花；文化卡左下角显示小织，不遮挡作品或免责声明。
- 同尺寸画布与固定锚点，图片加载后才做 360ms 交叉淡入。快速切换不会被延迟返回的旧图片覆盖；加载失败保留上一张，初始加载失败尝试标准图，全失败保留文字。
- 呼吸幅度约 1%，欢迎与庆祝只播放一次；休息、头像不循环运动。`quiet`、应用设置和系统减少动态效果均关闭动画与淡入。组件卸载清理定时器。
- 开发样张：`/pages/dev/ui-kit` 可手动切换全部状态，并比较 40px / 48px 头像。状态映射统一在 `src/utils/xiaozhi.js`，没有修改对话业务状态机。
