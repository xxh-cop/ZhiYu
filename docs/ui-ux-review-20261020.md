## 本轮已经落地

1. 成长旅程增加同量表、同版本的完整自评回看，可选择近 30 天、近 90 天和已载入记录；点击分数查看日期与当次说明。已知量表使用固定完整分数轴，不因两次记录相近而放大变化。
2. 创作感受逐条显示开始前与创作后；缺失显示“未记录”。明确开始前的值是在结束时回顾填写，不能据此认定干预效果。
3. 增加超过 365 条时的范围提示，后端按更新时间与编号稳定排序；历史记录渐进展开，活动反馈不再混入量表展示。
4. 新增区域具备手机单列、桌面双列布局，保留小织；按钮有可见焦点、选中语义、至少 44px 点击高度，H5 支持 Tab、回车操作；无记录时提供继续行动入口。
5. 清除记录的确认文案明确包含活动反馈，与服务端实际删除范围一致。

代码入口：`zhiyu-app/src/components/JourneyInsights.vue`、`zhiyu-app/src/pages/journey/index.vue`、`zhiyu-app/src/utils/journey-insights.js`、`zhiyu-backend/src/main/java/com/zhiyu/modules/growth/GrowthService.java`。
