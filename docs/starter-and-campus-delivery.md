# 织愈第四阶段：入门手作、可靠恢复与校内支持

交付日期：2026-10-11。服务场景：江西师范大学人工智能学院，江西南昌。

## 已落实

- 用户端「开始 → 从第一件手作开始」：按 10/15/20 分钟、纸/线材料、宿舍桌面/图书馆/活动室筛选，支持排除剪刀；说明推荐原因，支持换一个和无结果重选。选择只用于当前页面，不生成心理画像。
- 准备页：材料用量、替代品、勾选清单、编辑风险提示、四步预览、每一步失败补救、来源与版本。清单仅在页面内存保留。
- 创作：服务端读取本人已有进度，暂停状态不会自动继续；保存成功才推进步骤，失败留在原步并可重试；页面隐藏停止计时，重新显示重置停留时长。创建请求通过项目行锁串行化，避免同项目并发重复创建。
- 创作配图：原创 CSS 纹样示意，不是实物照片或完整技法图解；操作以文字为准。
- 校内支持页：真实官网、咨询联系、地点、学院公开邮箱、核对日期和联系准备。页面不会自动发邮件、提交预约或上传心理记录。
- 管理端工作台：新增入门手作开始/完成/暂停/放弃与完成占比。只展示管理员可见的真实汇总，无身份或心理文本；无数据时占比为“—”。这不是首次用户转化率，也不代表临床疗效。

## 网上核实与原创边界

1. [江西师范大学心理教育中心官网](https://xlyz.jxnu.edu.cn/)：咨询联系与办公地点来自官网页脚。服务时间未作推测，提示查看最新通知或联系确认；普通咨询联系不等同于紧急救援。
2. [江西师范大学人工智能学院官网](https://sai.jxnu.edu.cn/main.htm)：学院邮箱与地址来自官网。邮箱仅用于学院事务，不假定学院承担本产品隐私受理，也不宣称本项目已获学校授权。
3. [福建省政府：中国剪纸文化介绍](https://fujian.gov.cn/english/cultureandtravel/cultureandarts/202501/t20250106_6619079.htm)：仅作剪纸文化背景参考。
4. [MassArt Art Museum：Weaving With Paper](https://maam.massart.edu/weaving-with-paper)：核实上下交错的纸编基础原理，仅作背景参考。
