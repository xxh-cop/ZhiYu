## 1. 现状盘点

**现有形态**：Q 版动漫少女——棕色双丸子头（右側红珠+金发簪）、金棕大眼、浅薄荷青汉服、
**橙红腰封+红色蝴蝶结**。6 张 PNG（avatar/blink/talk/thinking/caring/happy，各 80–100KB，
AI 生成，画布未对齐导致眨眼有缩小感，[thinking 图带「豆包AI生成」水印]）。
logo.svg 已是青玉案 `#217e76` 底 + 白色交织线心形 + 暖金点——**品牌符号（交织线）与小织形象目前是脱节的**。

**出现位置与尺寸**：AiCompanion 悬浮件（全页可拖动，~120rpx）、XiaozhiCard 内嵌卡（首页/开始页）、
对话页头像与状态、隐私/空状态插画。状态机（idle/blink/talk/thinking/caring/happy）已在
`stores/aiCompanion.js` 实现，**行为层可完全复用，只换皮**。

**现状的三个硬伤**：① 橙红腰封与青玉案「避开饱和红」的原则冲突；② AI 生图多状态一致性差、
带水印、画布不齐；③ 动漫少女画风在 48px 头像尺寸糊成一团，且需要持续的高质量插画供给。

## 2. 三套方向

### 方向 A · 汉服小织（延续重绘，保守案）

- **造型语言**：保留双丸子头+汉服剪影（老用户一眼认出），改为扁平几何风：
  圆脸、直刘海、交领右衽用两条硬线交代，去掉一切细碎褶皱。头身比 1:1.2（现在约 1:1），更Q更稳。
- **非遗元素（取二）**：**针与线**——发簪替换为一枚小棒针+金珠；胸前佩交织线心形（与 logo 同符号）。
  放弃绣绷/纹样：衣服印花在 48px 全是噪点。
- **配色**：汉服 `#217E76`（全身占比约 45%），领缘 `#5BC4A8`，腰封由橙红改暖金 `#D9A441`（仅腰带与发饰，<10%），
  **绛红不用**——角色身上出现危机色语义混乱，这同时解决现橙红腰封的冲突。
- **风险**：人脸+头发的结构复杂度决定它仍需要插画师级供给；AI 生图很难保证 6+ 表情一致性（现状即证据）。

### 方向 B · 线团小兽（推荐，桌宠案）

- **造型语言**：一团毛线成精——正圆线团身体（头身一体 1:1），两条短线手，
  一根棒针斜插头顶当「呆毛/发簪」，线头尾巴自然垂落。**剪影 = 圆+针，3 米外可辨**。
  大眼+高光，腮红两点。没有头发、衣服、手指这些高成本结构，所有表情只靠眼睛+嘴+身体形变完成。
- **非遗元素（取二）**：**线团与棒针**。理由：它们是品牌动词「一针一线」的本体，
  角色本身就是材料而不是「穿非遗衣服的人」——非遗感从装饰变成存在。
  放弃织梭/绣绷/绢帛：都是外加道具，且梭与绷带强地域工艺指向，缩小后是杂线。
- **配色**：线团身体 `#217E76`（占比 ~70%，角色即品牌色），缠绕线 `#5BC4A8`/`#C9E4DD` 提亮，
  腮红与棒针珠用暖金 `#D9A441`（<8%，仅图形），腹部浅色块 `#EAF4F1`。**绛红不用**（同 A 的理由）。
- **桌宠天赋**：球形身体天然适合挤压拉伸（squash & stretch）——呼吸是圆球的轻微胀缩，
  被点击是 Q 弹下压回弹，打盹是慢慢歪倒。这是三套里唯一「不用画新手也能演」的方向。

### 方向 C · 梭灵（织梭精灵，**不推荐**，列出以示取舍）

- 织梭+飘带线尾的飞行小精灵。非遗指向最直接，但：无手无脚无法做动作；
  梭形细长，表情区面积太小；48px 下就是一根绿条。**桌宠感三项全输，明确不推荐。**

## 2.1 方向 B 精致化规范（2026-11-02 定稿，用户已拍板选 B；主色亮青）

> 主色定案：**亮青 `#5BC4A8`**（2026-11-02 用户拍板，取代初稿深青 `#217E76`）。
> 独立资产：`output/design/mascot/svg/`（10 个 SVG，清单见 §7 更新）；生成器 `.ai-tmp/gen-mascot-svg.js` 可复现。

### 亮青补偿方案（对比度实算驱动）

亮青身体的两个必然问题与解法（数值均为 WCAG 相对亮度实算）：

| 问题 | 数值 | 解法 |
|---|---|---|
| 身体对页面底 `#F5F7F2` 轮廓弱 | 1.97:1（纯白 2.12:1） | **外轮廓 `#1A645E` 2.5px 描边**（对页面底 6.43:1、纯白 6.93:1）；不加外发光（亮底上发灰发脏），不压暗身体 |
| 腮红 `#D9A441` 在亮青上不可见 | 1.06:1 | 腮红改 **深金 `#8A6D1F` 半透**（2.31:1，纯装饰非识别要素）；金珠保留 `#D9A441`（位于轮廓外/页面底上，图形点缀合规） |
| 深色态关系 | 身体对 `#14201C` 7.91:1 | 主体天然不糊；外圈由初稿 `#5BC4A8`（与身体同色失效）改 **`#C9E4DD` 3px**（12.47:1） |

五官不压暗的证明：`#233D34` 对亮青身体 **5.54:1**（`#0F3D38` 5.68:1），
超过 AA 正文线，48px 下眉眼嘴可辨无忧；线股凹槽用 `#1A645E`（3.27:1）与 `#175C55`（3.67:1）。

### 线股画法（毛线质感）

- **缠绕方向**：全部线股朝一个方向（左上→右下），11 股纬度弧 + 3 股经向弧交叠；
  受光侧用 `#EAF4F1`/`#C9E4DD`，中间调 `#3D9E8E`，背光侧与凹槽用 `#1A645E`/`#175C55`（亮青版深阶化）。
- **起毛**：16 根 2–2.5px 短纤维只在轮廓边缘放射状伸出（`#3D9E8E`/`#2D9B8F`/`#1A645E` 混色），不进脸部、不超过 9px。
- **明暗**：左上 radial 高光（36%,28%，白 32%→0）、球体 radial 渐变（`#8ADCC6→#5BC4A8→#3D9E8E`）、
  底部接触阴影椭圆（`#0F3D38` 18%）、外轮廓 `#1A645E` 2.5px。
- **线头尾巴**：双弯钩线头（`#3D9E8E`，与身体区分），动画里延迟 .8s 摆动（次级动作）。

### 材质区分

- 毛线：哑光绒毛 = 纤维 + 低对比渐变，无高光点。
- 竹棒针：哑光竹质 = `#D8BC8F→#A9854F` 线性渐变 + 两道竹节纹 + 针尖三角（`#8A6D3F`）+ 入球处接触阴影；
  顶部金珠 `#D9A441` 带一点 `#F3D9A0` 高光（全角色唯一高光点，材质对比靠它拉开）。

### 表情细节表（六态一眼可辨）

| 状态 | 眼 | 眉/眼睑 | 嘴 | 腮红 |
|---|---|---|---|---|
| 平静 | 圆眼+双高光 | 平 | 微笑 | 55% |
| 倾听 | 放大 15% + 高光加大 | 平 | 小 o | 60% |
| 思考 | 半闭（ry 减半）+ 眼睑线 | 一边上挑 | 平线 | 45% |
| 开心 | 弯月闭眼 | — | 张嘴笑+金舌线 | 70% |
| 安抚 | 垂眼（下弧闭眼） | 内端下垂 | 浅笑 | 60% |
| 困倦 | 下弧闭眼 | — | 微张 | 40% |

### 动效曲线与次级动作

呼吸 4.2s `cubic-bezier(.45,0,.55,1)`（scale 1.03/.972 + translateY -5px）；
眨眼快合 120ms 慢开 180ms（非匀速）；点击 squish .55s `cubic-bezier(.34,1.56,.64,1)`（压扁 1.14/.78→过冲 .94/1.07→归位）；
打盹 7s 歪倒 7°+Zzz 间隔 1.1s；思考 1.3s 小颠+棒针 .9s 快抖；安抚 6s 长呼吸不眨眼；
庆祝 1.6s 压扁→跳 -18px→落地回弹。**棒针永远比身体慢 .5s、线头再慢 .8s**——这是「有重量」的关键。

### 尺寸简化规则

- 96px：去纤维、去经线，线股保 5 条加粗；
- 48px：只留 3 股加粗线（7px）+ 大眼（眼放大 15%）+ 棒针示意，**是重画不是等比缩小**；
- 深色态：不重画，叠 `#5BC4A8` 3px 亮描边即可；
- 单色线稿：去全部填充，5px `#233D34` 描边。

## 3. 推荐结论

**推荐方向 B「线团小兽」**，三个评判角度：

| 角度 | B 线团小兽 | A 汉服小织 |
|---|---|---|
| 像不像桌宠 | 球形挤压拉伸，物理感与生俱来；idle/点击/打盹都成立 | 人形做动作要画骨骼级帧，CSS 只能做整体浮动，生动度上限低 |
| 能不能落地 | 纯几何形，SVG 单文件可派生全部表情；AI 生图一致性要求低；美术可外包也可自制 | 需要持续高质量插画；现状 6 张 PNG 的不一致就是教训 |
| 和青玉案搭不搭 | 身体即 `#217E76`，角色=品牌色球，金点呼应 logo | 主色占比不足一半，且要处理腰封改色的认知断层 |

A 作为保守备选：若评审/用户强烈依恋既有少女形象，A 是零认知成本的退路，但要接受更高的美术预算。
C 不推荐（理由见上）。

## 4. 技术方案对比与降级阶梯

| 方案 | 包体积 | 首帧 | 内存 | 小程序兼容 | 美术改动成本 | 结论 |
|---|---|---|---|---|---|---|
| **序列帧（WebP/PNG）+ CSS transform**（推荐） | 8 态×2–3 帧，WebP 约 150–250KB 总量 | 快（首帧即首图） | 低 | `<image>` 全支持（PNG/WebP 真机可显） | 改一张重导一批，低 | **主方案** |
| SVG + CSS 动效 | 单文件 <30KB | 最快 | 最低 | H5 可内联；**小程序 `<image>` 不支持 SVG**（经验判断，需真机验证；可用 PNG 导出兜底） | 改 SVG 源文件，最低 | H5 主用，小程序用其 PNG 导出 |
| Lottie（lottie-miniprogram） | runtime ~100KB+ + JSON | 中 | 中高（canvas 常驻） | **已查证**：需基础库 ≥2.8.0；canvas 原生组件有层级/显隐坑，动态创建 canvas 与图片处理受限，真机有失败案例 | 需 AE/Bodymovin 流程，高 | 仅在未来动作复杂度超标时评估 |
| Canvas 骨骼（如 Spine/自研） | 最大 | 慢 | 高 | WebGL 可用但杀鸡用牛刀 | 最高 | 不考虑 |

**推荐路径**：美术源文件用 SVG 绘制（矢量母版）→ 导出两路：
H5 直接内联 SVG + CSS 动效（呼吸/眨眼/挤压用 transform 作用于分组）；
小程序用 512×512 WebP 序列帧 + 同一套 CSS 关键帧切换帧与位移。
AiCompanion 现有拖动/隐藏/状态机逻辑不变，只换渲染层。

**降级阶梯**（每级都可独立开关）：
- L1 完整：呼吸 + 眨眼（双帧）+ 偶发小动作（每 8–15s 随机一次歪头/挥手）；
- L2 省流：关偶发动作，呼吸降频；
- L3 低耗：仅眨眼双帧切换，无位移动画；
- L4 静态：单张 PNG（`prefers-reduced-motion`、低端机、小程序基础库过低时）。
- 检测依据：`prefers-reduced-motion` 媒体查询、页面 `onHide` 暂停计时器（现有 aiCompanion store 已有计时器框架）。

## 5. 设计规范

- **画布**：母版 512×512px，安全边距 8%（41px），角色主体占画布 70–80%。
- **最小可用尺寸**：48px（对话头像）——B 案在 48px 仍是「绿球+眼+针」可辨；A 案在 48px 五官可读但发饰丢失。
- **配色占比**：品牌青玉 ≥60%，暖金 ≤8%，浅色腹部/留白 ≤30%，绛红 0%。
- **安全区**：头像裁切为圆形时，头顶棒针不得出血；深色态直接使用亮色描边版（`#5BC4A8` 描边），不重画。
- **单色/线稿版**：填充全去、保留 2px 描边（`#233D34`），用于打印物料与低配 fallback。
- **版权**：母版 SVG 为仓库原创资产；若用 AI 出方向稿，正稿必须人工重绘并在「关于」页声明（延续建议书 7.2 的版权要求，解决现水印问题）。

## 6. 表情与行为对应表

| 状态 | 表情（眼/嘴/体） | 触发（复用现有 aiCompanion store 事件） | 行为 |
|---|---|---|---|
| 平静 idle | 圆眼+微笑 | 默认 | 呼吸胀缩（4s 周期）+ 每 4–6s 眨眼 |
| 倾听 | 眼微大+嘴小 o | 用户正在输入 | 身体前倾 2°，眨眼变慢 |
| 思考 | 眼半闭+嘴平+棒针微颤 | sendMessage 后等待首个 token | 上下小幅度颠（1.2s 周期） |
| 说话 | 张嘴双帧 | SSE chunk 到达 | 现有 avatar↔talk 双帧切换复用 |
| 开心 | 弯月眼+大笑 | 作品发布成功、完成创作 | 弹跳一次（squash→stretch→落地） |
| 安抚 | 垂眼+浅笑+腮红显 | crisis 命中、用户连续低落 | 缓慢呼吸（6s）+ 不眨眼不打扰 |
| 困倦 | 闭眼+Z z z | 夜间（22:00–7:00）或 5 分钟无交互 | 身体缓慢歪倒 8°，Zzz 飘出 |
| 被点击 | 挤压帧 | click（非拖动） | 下压 12% 回弹 + 随机气泡（现有逻辑） |
| 收起 | 闭眼静态 | 拖到底部 | 现有逻辑（贴边收起）不变 |

视线/鼠标跟随：H5 做眼球 ±4px 偏移（transform，低成本高生动感），小程序端不做（无鼠标，触摸拖动已有）。
