# 织愈 · 90 秒旗舰闭环演示脚本

- 日期：2026-10-30
- 目标：用一条完整闭环讲清「非遗手作 + 有界小织 + 成长旅程 + 可治理」。
- 当前环境：后端 8080、学生 H5 5173、管理端 5777；根目录 `.env` 已注入 DeepSeek Chat + 豆包 Embedding。启动后端前必须先加载 `.env`；管理端应显示 `chatMode=EXTERNAL`。未注入时会回退本地引导，界面会明确标注。
- 演示账号：学生 `student01 / stu12345`；管理员 `admin / admin123`。
- 红线：不展示诊断、疗效结论或真实用户数据；全程保留「本系统不能替代专业心理咨询」。

## 一、演示前检查（不计入 90 秒）

```bash
# 后端：只把 .env 注入当前进程，不提交、不回显
cd zhiyu-backend
set -a; . <(tr -d '\r' < ../.env); set +a
mvn spring-boot:run "-Dspring-boot.run.profiles=dev" "-Dmaven.repo.local=../.ai-tmp/m2"

# 学生端 H5
cd zhiyu-app
npm run dev:h5

# 管理端
cd zhiyu-admin-vben
pnpm dev:ele
```

确认：

- `http://localhost:8080` 已启动，MySQL 可连接。
- `http://localhost:5173` 能用 `student01` 登录。
- `http://localhost:5777` 能用 `admin` 登录，并打开「AI 治理」。
- 管理端「AI 治理」应显示 `chatMode=EXTERNAL`、`vectorMode=LOCAL_FILE`；trace 中应出现 `EXTERNAL`。
- 管理端「AI 治理」能看到 trace 与评测集；如果 trace 为空，先跑一次学生端陪伴消息。

| 时间 | 画面 | 台词（可直接照读） |

## 三、关键时刻的准确说法

- 「小织」是**受控陪伴编排**，不是自主 Agent：模型只能输出 JSON 计划，阶段、工具、会话状态都由后端校验。
- 当前真实模型已接入：DeepSeek Chat 生成，豆包 Embedding 负责本地向量索引；界面 `generated=true` 时显示「小织」，不显示「本地引导」。
- 真实模型仍不是医疗设备：不做诊断、不给药物剂量、不承诺疗效；诊断类输出被安全改写时 trace 记录 `OUTPUT_REWRITE`。
- 工具只有 `recommendPractice`、`searchHeritage`、`suggestBreathing` 三个只读工具；没有删除、跨用户读取或写库工具。
- 自适应计划是**规则驱动**（时间、最近完成/放弃记录、授权偏好），不是模型生成；推荐卡会展示原因，且明确“只调整练习节奏，不作情绪或疗效判断”。
- 危机输入走本地高危词库：直接返回支持话术与热线，不调用模型、不执行工具。
- 文化卡保存的是**练习成果**，不是作品图片；删除只软删成果，不回退会话。

## 四、演示失败时的降级

| 故障 | 处理 |
|---|---|
| SSE 超时或网络断 | 小织面板会显示「可以再试一次，或继续手动练习」；直接继续手动完成 4 步，不要停在空白页。 |
| 真实模型不可用 | 若 `.env` 未加载或网络失败，界面会显示「本地引导」；明确说「本次发生降级，真实模型联调已做过，但当前回复不是模型生成」。 |
| 后端重启 | 先在「开始」页创建新会话；旧会话可能处于练习中，可在「成长旅程」继续。 |
| 管理端 trace 为空 | 先完成一次小织消息，再刷新 AI 治理页；不要现场伪造数据。 |
| 管理端登录失效 | 重新用 `admin / admin123` 登录；不要展示 token 或浏览器控制台。 |

## 五、演示后清理

- 学生端测试会话可在「成长旅程」查看；不要删除真实用户数据。
- 真实模型调用会产生费用：彩排与正式演示各控制 1–2 条消息，避免循环刷接口。
- `ai_trace` 只追加，不手工修改；演示产生的 trace 可保留用于治理页展示。
- 如必须清理测试会话，按明确记录的会话 ID 删除；不要执行全表清空。
- 演示结束不要展示 `.env`、终端环境变量或浏览器控制台中的 token。

## 六、不要说的话

- 不说「AI 能诊断/治疗/治愈」。
- 不说「做完这个手作就不会焦虑」。
- 不说「模型已经全部验证」；当前完成了真实模型首轮 10 条红队，仍需定期复测。
- 不展示真实用户对话、token、手机号或未脱敏截图。
