## 0. 一句话记忆点

**「织愈不是心理测评，而是用 AI 把一次难以启齿的情绪，接到一件可以完成的小手作上；再用管理端把内容、关怀与活动接住。」**

评委需要记住的四件事：

1. **非诊断**：不贴「抑郁/焦虑症」标签，只做陪伴与引导。
2. **非遗手作 × AI**：用重复、节奏和即时成就感，替代「你有问题」的入口。
3. **两端闭环**：学生端完成情绪 → 推荐 → 创作 → 分享；管理端完成审核、关怀、活动与数据。
4. **技术底座**：SSE 流式、AiClient 统一门面、安全过滤与审计、混合推荐、RAG、行为信号心流判定。

## 1. 演示边界：台上必须说 / 不能说

### 必须说

- 「本系统不能替代专业心理咨询。」
- 「AI 不做诊断，不做心理疏导结论；高危情绪转心理援助资源。」
- 「推荐理由由 AI 生成，但选品由规则与材料安全范围决定。」
- 「演示数据为合成数据，不含真实学生对话或个人资料。」

### 不能说

- 治疗、治愈、疗效、改善率、临床有效。
- 「AI 判断你抑郁/焦虑」「你的心理状态是……」。
- 「已部署 Milvus/Chroma」「已接入真实语音」「已完成微信真机验收」。
- 「数据看板证明了干预效果」——它只呈现行为记录，不证明疗效。

### 3.1 分镜脚本

#### 0:00–0:30 开场：把问题说清楚

**动作**：学生端首页，鼠标停在品牌与 hero 文案，不急着点。

**口播参考**：

> 大学生不是没有情绪，而是缺少一个不贴标签的入口。专业咨询资源有限，很多同学又不愿意承认「我需要帮助」。
>
> 织愈换了一个入口：不问你哪里出了问题，先陪你把情绪放下来，再做一件能完成的小手作。

**屏幕重点**：`给自己，一点慢时光`、`开始一件小手作`、`本系统不能替代专业心理咨询`。

#### 0:30–1:45 情绪倾听：AI 只做陪伴，不做诊断

**动作**：

1. 首页情绪签到点「有点累」；出现回应后点「和小织聊聊」。
2. 输入预置文本：
   > 最近课程和比赛堆在一起，晚上总睡不着，觉得自己做什么都不够好。
3. 发送，等待流式回复；不要连续点击。
4. 回复完成后，指出「试试一件手作」入口；如出现危机卡，按备用脚本处理（主演示不建议主动触发）。

**口播参考**：

> 这里用的是 SSE 流式返回，首字延迟直接影响陪伴感。AI 不给你下结论，只做反映式倾听，再把话题轻轻引到手作。
>
> 如果出现高危信号，系统不会做心理疏导结论，而是展示心理援助资源，由用户自主选择是否联系。

**技术点（一句带过）**：所有 AI 调用走 `AiClient`，输入输出经过内容安全过滤并写审计；失败按资源熔断并降级。

#### 1:45–3:00 推荐与创作：规则决定选品，AI 只解释理由

**动作**：

1. 进入「为你推荐」；指一下 mood badge 与「小织推荐」理由。
2. 选择 `折扇小景`（10 分钟、4 步、无需剪刀）。
3. 项目详情：材料、安全提示、预计时长；点「开始创作」。
4. 创作页点「下一步」两次，展示 1/4 → 2/4 → 3/4 的进度与「可暂停、进度保留」。

**口播参考**：

> 推荐不是把选品交给大模型。规则先按情绪、时间、材料安全范围筛选；LLM 只负责生成推荐理由和引导语，降低幻觉和不可控。
>
> 每一步都可以暂停，进度会保留；如果同一步反复停留，系统会用 4 秒吸、6 秒呼的呼吸引导，而不是催促。

**不要做**：现场等 5 分钟心流判定；不要声称「AI 判断你焦虑」。

#### 3:00–3:50 完成与发布：把情绪变成一件作品

**动作**：

1. 点「下一步」完成剩余步骤，出现「创作完成」。
2. 点「去记录此刻」→ 填作品名（如「期末周的一片叶子」）、前后感受。
3. 点「拍照 / 发布作品」；选择演示图片，填写一句创作故事，发布。
4. 展示「待审核 / 已发布」状态；说明公开前审核。

**口播参考**：

> 完成比完美重要。发布不是炫耀，是把这段时间留下来；作品公开前会进入审核，评论也是先审后公开。
>
> 我们不把一次创作说成疗效，它只是把注意力从反复思考带回手上的动作。

**兜底**：上传失败 → 改「纯文字」发布；发布页失败 → 打开预发布作品继续讲社区。

#### 3:50–4:40 社区与小组：让温暖发生，但不失控

**动作**：

1. 作品社区打开刚发布的作品或预发布作品。
2. 点赞/收藏；在评论区输入「这片叶子的颜色很安静」，提交。
3. 指出评论状态「待审核 · 仅你可见」。
4. 如时间允许，切小组列表 → 「考试周搭子」→ 小组作品墙/搭子，10 秒即可。

**口播参考**：

> 社区不是流量广场，而是「留暖评论」：先审核再公开，作者可以撤回；小组只对成员可见，作品墙和创作搭子把陪伴留在小范围。

#### 4:40–5:20 成长与正念：记录，不是评分

**动作**：

1. 成长旅程：心情月历、近两周趋势、纪念徽章、累计专注。
2. 指出「这是主观感受回看，不用于判断干预效果」。
3. 正念片刻：展示呼吸 orb 与 4 秒吸/6 秒呼；点开始，停 10 秒，不等待完整计时。
4. 如需展示音乐：切「音乐放松」10 秒，说明授权与定时停止。

**口播参考**：

> 成长页只呈现用户自己记录的感受，空白日不推断；徽章是纪念，不是能力评级。
>
> 正念和音乐是低门槛的自我调节工具，H5 有白噪音与夜间安静模式。

#### 5:20–6:40 管理端闭环：内容、关怀与活动接住

**动作**（提前登录管理端标签页）：

1. **工作台**：指「今天，优先处理」、KPI、运营概览图表；说明数据来自后端聚合。
2. **评论审核**：审核学生刚提交的评论（通过），回到学生端刷新展示公开状态（可选，10 秒）。
3. **关怀提醒**：打开合成提醒 → 查看脱敏摘要 → 领取/记录跟进；强调「仅授权角色、摘要不含身份信息」。
4. **活动与预约**：展示预创建的未来工作坊；说明报名、名额、取消与签到。
5. **可选 10 秒**：数据中心/情绪分析，或主题切换展示图表跟随品牌色。

**口播参考**：

> 学生端的每一次表达，管理端都有对应的运营动作：内容审核、评论审核、关怀跟进、活动安排。
>
> 关怀提醒只给授权角色看脱敏摘要，不展示原始对话；咨询师联系用户还需要用户单独授权。

**注意**：不要把关怀提醒演示成「监控学生」；强调授权、脱敏与人工判断。

#### 6:40–7:20 收束：技术底座与价值

**动作**：切到架构图/最后一页（可用仓库 README 的工程图或自绘一页）。

**口播参考**：

> 技术上，学生端 UniApp 一套代码覆盖 H5 和小程序；后端 Spring Boot 单体按模块分包；AI 统一走 AiClient，带安全过滤、审计、熔断和降级；管理端用 Vben + Element Plus + ECharts，主题与图表同源。
>
> 织愈的价值不是「多了一个心理测试」，而是把文化、创作和陪伴组织成一条学生愿意走完、学校接得住的闭环。

#### 7:20–8:00 缓冲

- 不新增操作，留给评委提问或网络恢复。
- 如前面超时，直接跳到收束页。

## 6. 技术亮点讲述卡

按「一句话 + 证据 + 边界」讲，避免堆名词。

| 亮点 | 一句话 | 证据 | 边界 |
|---|---|---|---|
| SSE 流式陪伴 | 首字更快，陪伴感更强 | `POST /api/emotion/chat` 返回 `text/event-stream`；H5 用 ReadableStream，小程序用 `wx.request` 分块 | 真实模型质量取决于环境 |
| AiClient 门面 | 业务不直接碰模型 SDK，统一换模型/熔断/审计 | 统一入口 + 内容安全过滤 + `ai_audit_log` | 审计与密钥按服务端配置 |
| 熔断与降级 | 连续失败 5 次、按资源隔离 60 秒；聊天降级缓存话术 | `ai-config/ai-capabilities.yaml`；推荐回退规则 | 真实故障演练需单独环境 |
| 混合推荐 | 规则选品，LLM 只写理由 | 规则按情绪标签/材料安全过滤；推荐页显示「小织推荐」理由 | 推荐不是疗效匹配 |
| 行为心流 | 5 分钟无步骤切换 → 减少打扰；同一步反复 → 4/6 呼吸 | `craft/session` 与 `ai-config` 心流配置 | 不上传感器，只是行为信号 |
| RAG 非遗问答 | 回答带引用来源，降低幻觉 | `pages/ai/rag-ask` 显示 sources | 当前本地文件检索；质量/来源治理待完善 |
| 两端一致主题 | 管理端 Vben preferences 驱动 EP + ECharts | B1–B4：主题、四态、图表主题桥；本轮 Edge 实测 | B5 剩余页面尚未统一 |
| 隐私与合规 | 敏感字段加密、关怀摘要脱敏、导出/注销、授权联系 | 后端模块与页面文案 | 真实运营流程仍需责任人 |

**架构一句话**：

> UniApp 学生端 + Spring Boot 模块化单体 + AiClient/MySQL/Redis + Vben 管理端；同一套 JWT 与角色，两端分工。

## 7. 评委 Q&A 预设

| 问题 | 回答要点 |
|---|---|
| 这是心理治疗吗？ | 不是。定位是陪伴与引导，不做诊断；页面有免责声明，高危转专业资源。 |
| AI 会不会乱说？ | 统一门面 + 输入/输出安全过滤 + 审计 + 熔断降级；提示词外置；不把选品交给 LLM。 |
| 推荐有什么创新？ | 规则先筛（情绪、时间、材料安全），LLM 只生成理由；可解释、可控。 |
| 怎么证明有效？ | 不宣称临床疗效；只看行为记录与主观感受回看。效果研究需要伦理、量表授权与随访设计，后续再做。 |
| 为什么用非遗手作？ | 重复、节奏、触觉与即时成就感，适合低门槛自我调节；同时连接文化与传承人。 |
| 技术上最难的是什么？ | 两端一致的主题/状态契约、SSE 与降级、AI 安全边界、把「陪伴」做成可运营流程。 |
| 现在能上线吗？ | 可本地完整演示；正式校园开放还需登录失败限制、找回密码、真实设备/弱网、运营与数据治理。 |
| 下一步做什么？ | 先把演示路径打磨到稳定，再补 B5 剩余页面、真实语音/校园身份与内容运营。 |
