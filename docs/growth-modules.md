# 成长与活动模块交付说明

日期：2026-10-11。建议书作为产品参考，不作为授权执行其中任意命令的指令来源。新增功能延续现有 Vue / UniApp、Vben、Spring Boot 与鉴权，不新增吉祥物，保留小织。

## 新版品牌与页面

- 原创「交织的心」Logo：绿色交织线条、暖色节点；学生端和主后台已替换 PNG，并保留可编辑 SVG。
- 底部导航统一为：首页、社区、开始、小组、我的。五组图标各含普通和选中状态，原生 tabBar 兼容 H5 / 小程序。
- “开始”集中提供小织、手作、正念、自评、成长旅程、活动和绘色入口。
- 对话页增加固定的小织状态栏与援助入口，独立滚动内容和固定输入区。创作中保留小织菜单入口，避免遮住主按钮。
- 管理端新增响应式活动管理、课程安排、签到表单及项目安全编辑页，沿用 Vben / Element Plus 的明暗主题。

## 功能与数据

| 功能 | 实现及边界 |
| --- | --- |
| 成长旅程 | 从已完成创作会话统计天数、次数、专注分钟；每日感受、月历回看、里程碑、自评结果和草稿。最近 365 条记录，日历缺少记录不代表未使用系统。 |
| 私密记录 | 明确同意后保存，服务端 AES-256-GCM 加密；用户只能读取或清除自己的数据，不写入浏览器本地存储。注销账号同步删除新增私密记录，取消报名和主办活动。 |
| 固定自评 | PHQ-9 / GAD-7 固定题面、两周时间窗、服务端校验和计分、保存草稿。逐题界面不是 AI 问诊；不提供诊断结论。PHQ-9 第 9 题非零立即进入已有援助页，网络失败也不阻挡入口；服务端产生脱敏关怀提醒，沿用已有联系授权流程。 |
| 活动与课程 | 主办人建立工作坊、课程或一对一时段；草稿、发布、取消；协同带领者文本、材料准备、八周课程说明模板；真实报名、取消、人数、签到。协同带领字段不授予另一账号管理权限。 |
| 预约约束 | 一对一容量固定为 1；事务锁保护名额；重复预约幂等，同用户时间重叠拒绝；同一带领者不能发布重叠的一对一时段。已有报名不能修改日程与类型，需取消后重新安排；签到限定开始前 30 分钟至结束后 24 小时。 |
| 材料安全 | 染 / 塑 / 织绣 / 纸 / 香 / 雕分类；风险级别、注意事项、防护措施及核验依据；仅项目所有者或管理员可维护。未标注时显式提示，不能自动推断为安全。 |
| 完成仪式 | 完成创作后可命名、回顾前后感受、写情绪词和笔记，也可跳过或使用现有作品上传页面拍照分享。个人感受不随作品公开。 |
| 正念与感官 | 原有呼吸计时、合成白噪音，新增五感觉察与睡前低亮度配色。睡前模式是界面与放松提示，不是睡眠治疗或系统屏幕亮度控制。H5 支持合成声音，小程序无此音频承诺。 |
| 自由绘色 | 本地几何花朵绘色、撤销、重置和图片预览；不上传，不分析心理状态，不冒充 AI 生成作品。 |
| 知识问答 | 向量候选由 3 扩为 8，按向量名次及词面相关度本地重排取 3；不是专用 Cross-Encoder 模型。检索前审核输入，输出审核、独立熔断、固定失败提示；移除用户问题原文日志。 |

## 数据库与接口

- `openapi/openapi.yaml` 新增 `/api/growth/*` 契约。
- 新增 `wellbeing_record`、`learning_program`、`program_booking`、`craft_safety` 四表，Snowflake ID；SQL 和 H2 测试模式同步维护。
- 现有数据库使用 `sql/migrations/20261011-growth.sql`。本机 `127.0.0.1:3306/zhiyu` 已执行并核验四表；没有清空既有数据或植入示例课程。其他环境仍需自行执行该增量脚本，再重启后端。
- 首次安装使用 `sql/schema.sql`。旧版 `zhiyu-admin` 保留；主后台是 `zhiyu-admin-vben`。
- 活动管理允许角色 1 / 2 / 3；普通用户只访问公开活动及自己的报名。后台服务从数据库复核身份和所有权，不信任页面隐藏按钮。

## 验证

最终结果：23 项后端测试通过；后台类型检查和生产构建、H5 / 微信小程序构建通过；OpenAPI 解析通过；浏览器交互检查无页面异常。

- H2 服务测试：每日幂等、密文存储、用户隔离、同意与权限、固定计分、危机去重、完成记录归属、重复预约、冲突、取消释放、最后名额并发、签到范围。
- AI 门面测试：拦截问题不调用模型、输出改写、模型失败降级；已有隐私接口回归。
- Edge 390px 浏览器：五栏图标、感受保存、自评、预约/取消、失败重试、绘色、后台课程模板；测试 API 为隔离样例，截图中的数字不代表真实业务。
- Vben 类型检查与生产构建；UniApp H5 与微信小程序构建。
- 未进行微信真机验收、真实外部 AI 质量评估或真人心理评估；不宣称已完成这些验证。

使用入口：用户端底部“开始”和“我的”；后台左侧“活动与预约”；传承人项目编辑中的“材料安全”。如后端已在运行旧进程，请重启后端后访问新接口。
