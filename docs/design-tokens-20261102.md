## 1. 品牌色阶

| 令牌 | HEX | 用途 | 对比度结论 |
|---|---|---|---|
| `brand-50` | `#EAF4F1` | 选中态底、tag 底、轻提示区 | 装饰底，不承载文字 |
| `brand-100` | `#C9E4DD` | hover 底、用户气泡底 | 配 `text` 10:1+（参考族） |
| `brand-300` | `#5BC4A8` | **深色态主色**、浅色态图形/进度/插画 | 深底上 7.91:1 ✓；白底 3.39:1 仅图形/大字 |
| `brand-500` | `#2D9B8F` | 浅色态 hover、链接 hover、图表序列 | 白底 3.39:1 仅图形/大字，不作按钮底 |
| `brand-600` | `#217E76` | **主色**：主按钮底、链接、导航选中 | 白字 4.87:1 ✓；白底 4.87:1 ✓ |
| `brand-700` | `#1A645E` | 主按钮按下态、深色文字强调 | 白字 6.93:1 ✓ |
| `brand-900` | `#0F3D38` | 深色态按钮文字（配 brand-300 底） | brand-300 上 5.68:1 ✓ |

**按钮规则**：浅色态主按钮 = `brand-600` 底 + 白字（4.87 ✓）；hover 用 `brand-700`；
**禁止**用 `brand-500`（3.39 不达标）做按钮底——这是现行学生端要修的点。
深色态主按钮 = `brand-300` 底 + `brand-900` 字（5.68 ✓）。

## 6. 既有资产映射

### 6.1 学生端（zhiyu-app `src/styles/theme.scss` / `uni.scss`）

| 现状 | 去向 | 动作 |
|---|---|---|
| `--wot-color-theme: #2D9B8F` | 拆为 `brand-600`（按钮/链接）+ `brand-500`（图形/hover） | **替换**：按钮/链接改 `#217E76`，`#2D9B8F` 降为 hover/图形 |
| 辅助文字 `#586e62` / `#718478` | `text-secondary #4A5F54` | **替换**（对比度修正） |
| 背景 `#F8F9FB`、tint `#F0F9F7` | `bg #F5F7F2`、`tint #E8EFE4` | **替换**（并入 tokens 族） |
| 暖橙 `#FFB547`、珊瑚红 `#FF6B6B` | `accent-gold #D9A441`（仅图形）、`care #A64842` | **替换**（珊瑚红正是要避开的焦虑红） |
| 动效 token（duration/easing） | 不变 | **直接复用** |
| 圆角 18/10、阴影、间距 | 不变 | **直接复用** |

### 6.2 管理端（zhiyu-admin-vben `apps/web-ele`）

| 现状 | 去向 | 动作 |
|---|---|---|
| Vben 主色 indigo `#4F46E5`（preferences） | `brand-600 #217E76`（HSL 三元组写入 preferences） | **替换** |
| `--zy-glass-*` 全套（表面/模糊/描边/内高光） | 从 `hsl(var(--primary)/a)` 自动派生 | **直接复用**（换主色即跟随，这正是当初派生设计的价值） |
| `--zy-ambient` 环境光中硬编码蓝色 `hsl(205deg 82% 46%)` | 改取 brand 色相（≈174deg） | **替换**（唯一的硬编码非品牌色点） |
| `.dark` 表面 ramp（228deg indigo 系明度阶） | 改 174deg 青玉系明度阶，对应 `d-bg/d-surface` | **替换** |
| 珍珠输入框 `--zy-pearl-*` | 派生自 card/foreground，自动跟随 | **直接复用** |
| `--zy-duration-*/--zy-ease-*`、animations.scss | 不变 | **直接复用** |

### 6.3 `design/tokens.json`

现为 12 键简表（`primary #2f7566` 等）——**整体重写**为本文件定义的完整令牌族，
保持单一事实源；`#2f7566` 作废（它正是「四色并存」之一）。
