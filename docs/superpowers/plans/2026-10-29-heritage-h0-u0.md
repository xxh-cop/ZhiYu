# 非遗 H0 内容底座与 U0 交互样板 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付四门工艺、二十四份有出处关系的原创教学构图、受约束的几何渲染核心，以及首页/纹样馆/创作三个可浏览器验收的视觉样板。

**Architecture:** 非遗事实与教学设计集中在后端 catalog JSON，作为 H1 导入和本轮样板的唯一内容源；几何核心只输出有限的归一化图形数据，可被 Canvas/SVG 消费。样板放在 design/student-experience，不注入生产路由，不伪装为已接数据库或真实 AI 的业务页面。

**Tech Stack:** 现有 Node 24 node:test、原生 JavaScript、HTML/CSS/SVG；不新增 npm 包，不改 Vue/UniApp/Wot 版本。

**Spec:** `docs/superpowers/specs/2026-10-29-heritage-student-experience-design.md`

> **2026-10-29 用户范围修订：** 原首页不改，只新增一个“非遗纹样馆”入口；原聊天、推荐、创作、发布、社区、小组、成长、正念、活动、隐私等功能全部保留。本计划中的首页样板仅作视觉参考，不作为生产首页替换；后续 H1/U1 只做入口和新增页面，不重排首页/开始页。

## Global Constraints

- 不自动提交、推送或切换分支；保留用户详细设计说明书与本次已确认总纲。
- 所有教学纹样标为“原创教学再设计”，不称传统原作、认证课程或文物复刻。
- 公开可读不等于允许复制照片或整篇文字。
- 正文/表单使用系统无衬线；少量章节标题可用系统衬线，不换 logo、不新增外部字体下载。
- 不执行模型 SVG/HTML，不引入第二套 UI 库、Lottie、Rive、GraphRAG 服务。
- 暂不改数据库、OpenAPI、真实业务状态、生产首页或现有绘色协议；H1/C1 承担集成。
- 样板交互使用原生语义控件；生产 UniApp 推广仍需 AccessibleButton/Wot 与真机验证。
- UI 样板必须由用户确认，再进入全站推广；本批通过不能将总项目任务勾完。

## Task 1：来源、工艺与原创设计目录

**Create:** `zhiyu-backend/src/main/resources/catalog/heritage-catalog.json`

**Test:** `zhiyu-app/tests/heritage-pattern.test.mjs`

**Interfaces:** 顶层 `{version, disclaimer, sources, traditions, patterns}`；数组内 ID 均字符串。来源字段为 `id/title/organization/url/accessedAt/mediaReuse/facts`；工艺字段为 `id/name/shortName/region/category/registryCode/listedYear/sourceIds/summary/materials/process/safety/practiceBoundary`；纹样字段为 `id/traditionId/name/family/variant/detail/palette/origin/sourceIds/designNote/learningFocus/minutes/level`。

- `origin` 固定 `ORIGINAL_STUDY`；`mediaReuse` 固定 `NOT_GRANTED`，表示项目页未明示媒体再利用许可，不代表网页作者许可结论。
- palette 恰有四个合法六位颜色，顺序为底、墨、主、辅；色板是项目界面设计，不冒称历史标准色。
- minutes 是编辑预估的数字绘色练习时长，不能描述为完成真实工艺的耗时。

- [ ] **Step 3：实现归一化几何，不操作 DOM**

矩形/多段线/椭圆离散点作为唯一基础图元：

```js
const point = (x, y) => [Math.round(x * 10000) / 10000, Math.round(y * 10000) / 10000]
const ellipse = (cx, cy, rx, ry, rotation = 0) => Array.from({length:32}, (_, i) => {
  const t = i * Math.PI / 16
  const x = Math.cos(t) * rx, y = Math.sin(t) * ry
  return point(cx + x * Math.cos(rotation) - y * Math.sin(rotation), cy + x * Math.sin(rotation) + y * Math.cos(rotation))
})
```

编织通过带条交错和交点覆盖表现上下层，twill/basket/chevron/diamond/window 分别改变拓扑而非仅颜色；针线组采用短线、点、叶瓣和弧线；剪纸组用底色与留白图层表达构图但不声称可直接实物剪刻；瓷器组用器面边界和独立装饰区表达结构。所有图元留在归一化画布内，fill/stroke 只能是 0–3 的色板索引，width 有限且不超过 0.05。
