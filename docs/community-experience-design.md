# 社区作品与收藏交互（2026-10-19）

## 本次完成

作品详情采用手机单列、桌面作品与交流双列布局。图片按比例展示并可预览，缺图与文字作品使用现有小织素材，视频沿用私有媒体播放组件。统一青绿底色、白色卡片、留白、字号和操作层级；加载、失败、空状态和底部安全区域均有处理。

留言直接在详情页填写，限制255字，与后端一致；失败保留内容，成功后提示待审核，加载更多失败可重试当前页。点赞与收藏从服务端恢复本人状态，提交期间防止重复点击。

我的收藏从个人页和详情页进入，支持分页、取消收藏和状态刷新。仅返回当前仍能访问的作品。取消收藏使用幂等删除接口，不会因重复操作重新收藏或影响点赞。

公开且审核通过的作品才提供分享入口，打开分享面板前重新读取权限。H5提供复制链接与可用时的浏览器系统分享；微信小程序通过用户点击分享按钮触发。分享只携带作品ID，使用通用品牌缩略图，不带视频签名、登录凭据或作者账号。接收者需登录；登录和注册均保留经过白名单校验的作品回跳地址。访问时仍由服务端检查作品状态，旧链接不能绕过私密或撤回限制。

## 参考及边界

- [Tencent TDesign 小程序开源仓库](https://github.com/Tencent/tdesign-miniprogram)：参考其组件划分与一致的交互状态处理思路；没有替换现有组件库或复制组件实现。
- [UniApp 分享文档](https://uniapp.dcloud.net.cn/api/plugins/share.html)：按平台区别接入，小程序使用主动分享按钮。
- [UniApp 页面生命周期](https://uniapp.dcloud.net.cn/tutorial/page.html)：使用页面加载及分享回调。

这是当前社区流程的实现与验证，不代表全站分享、微信真机或生产部署已验收。H5链接以当前部署地址生成；本机地址只能在可访问该环境的设备中打开。微信好友分享需要配置正确的小程序AppID并完成真机验证。
