# 活动与预约体验设计

本轮沿用现有框架，不引入另一套 UI 组件库。布局与状态反馈参考 [Vue Vben Admin](https://github.com/vbenjs/vue-vben-admin) 和 [Ant Design Feedback](https://ant.design/docs/spec/feedback/)，实现代码由本项目编写。

## 学生端

- 页面顺序为陪伴引导、下一项安排、检索与分类、活动列表；小织为内嵌形象，不遮挡操作。
- 统一使用项目绿色、浅色背景、白色卡片和可见边界；手机单列、平板两列、宽屏三列。
- 复用已登记来源的材料图片，并明确标为材料示意图，不冒充活动现场。
- 日期、预约状态、地点和名额优先显示；较长介绍与准备事项按需展开。
- 一对一提交后的文案是等待确认，不显示预约成功；取消、未通过的记录保留在我的预约。
- 加载显示骨架占位；失败显示重试；搜索无结果显示清除筛选入口；操作中禁止重复提交。
- 保留键盘焦点提示、文本状态标签和减少动效设置；不能只依靠颜色区分状态。

## 管理端

- 复用业务页标题组件，支持主操作插槽，不影响现有页面的刷新按钮。
- 预约处理中心独立呈现活动名称、待确认数量、加载/失败状态和行内处理按钮。
- 确认、拒绝和签到均有二次确认；服务器再次校验当前权限与状态，防止页面过期或重复点击。

## 验证边界

已检查编译、类型、真实接口和学生端浏览器交互。微信小程序通过构建，仍需开发者工具与真机验证。此页改造不代表所有页面都完成统一，也不能单凭截图宣称项目达到企业级生产标准。
