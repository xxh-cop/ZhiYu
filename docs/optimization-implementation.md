## 使用入口

- 主管理端为 `zhiyu-admin-vben`：`pnpm --filter @vben/web-ele dev`。
- 基础旧管理端 `zhiyu-admin` 本批未改，避免两套后台同时扩展。
- 学生端为 `zhiyu-app`：`npm run dev:h5`。首页点“正念片刻”；页面路径 `/pages/mindfulness/index`。
- 无新增数据库表、字段或后端接口，无迁移要求。
- 当前心情选择只是页面内状态，明确注明未持久化，不冒充已保存的心情记录。
- 正念练习不采集或存储心理数据，不作为评估量表。

## 本批验证结果

- Vben 生产构建及 TypeScript 检查通过。
- 学生端 H5 与微信小程序构建通过，确认小程序产物不含浏览器 AudioContext 调用。
- 后端 Maven compile 通过。
- Edge 浏览器隔离接口验证通过：工作台加载、失败保留旧数据、筛选折叠、图表渲染、390px 窄屏；呼吸开始、暂停冻结、时长切换、到时完成、离页暂停、白噪音停止；首页心情联动与入口；创作暂停/继续、步骤切换、完成失败后心跳持续及再次提交成功。上述检查未出现页面运行异常。
- 验证采用浏览器拦截测试响应，不写真实业务数据；未进行真实数据库端到端联调或微信真机测试。
